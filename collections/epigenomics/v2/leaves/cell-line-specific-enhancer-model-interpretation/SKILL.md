# cell-line-specific-enhancer-model-interpretation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Interprets the motif-module input features of the Enhancer-MDLF cell-specific enhancer predictor with the SHAP framework to rank TFBS motifs by importance within enhancer regions across eight human cell lines, producing per-cell-line motif rankings and SHAP force-plot diagrams.

## When to use

Use when you have a trained Enhancer-MDLF model on one of the eight human cell lines and need to identify which TFBS motifs drive enhancer predictions via SHAP attribution over motif-module features.

## When NOT to use

- The goal is to interpret the dna2vec sequence-embedding branch of Enhancer-MDLF rather than the motif-module features extracted by motif_find.py
- Sequences are outside the scope of the HOCOMOCO Human v11 PWM library or the enhancer data on the eight cell lines shipped in the 'data' folder
- No trained or pre-trained Enhancer-MDLF model is available and training it via main.py is out of scope for this interpretation task

## Inputs

- Independent enhancer test-set FASTA files per cell line (e.g. 'data/test/NHLF.fasta')
- Test-set label files (e.g. 'data/test/NHLF_y_test.txt')
- Pre-trained or per-cell-line trained Enhancer-MDLF models from the 'model' folder
- HOCOMOCO Human v11 motif PWMs and p-value threshold scores from the 'motif' folder
- Motif-module feature matrices generated by motif_find.py

## Outputs

- SHAP force-plot interaction diagrams saved per cell line in the 'force-plot' directory
- Per-cell-line ranking of TFBS motifs by SHAP-derived feature importance (top-50 motif features)
- Key motifs identified per cell line (BACH1 in HUVEC, GATA1 in K562, SP1 across cell lines)

## How to apply

Load the independent enhancer test-set FASTA files and labels (e.g. 'data/test/${cell_line}.fasta' and '${cell_line}_y_test.txt') together with the pre-trained/trained Enhancer-MDLF models from the 'model' folder. Generate motif-module input features by running motif_find.py, which scans sequences against the position weight matrices (PWM) and p-value threshold scores from the HOCOMOCO Human v11 database in the 'motif' folder, saving feature files to the 'feature' directory. Run SHAP.py to compute SHAP values over the motif-module features with the loaded model for each cell line, and save the SHAP force-plot interaction diagrams to the 'force-plot' directory. Aggregate SHAP attributions per motif feature to rank TFBS motifs by importance per cell line and extract the top-ranked motifs. Validate by confirming BACH1 ranks highly in HUVEC, GATA1 in K562, and SP1 across cell lines, and that a force-plot file exists for each of the eight cell lines.

## Examples

```
python motif_find.py --input_file data/test/NHLF.fasta --cell_line NHLF --set test
```

## Evaluation signals

- A SHAP force-plot interaction diagram file exists in the 'force-plot' directory for each of the eight cell lines
- BACH1 motif emerges exclusively among the top 50 important features in the HUVEC cell line
- GATA1 ranks highly among motif features in the K562 cell line
- SP1 ranks highly across cell lines rather than in a single cell line only
- Motif feature files produced by motif_find.py for train/test sets appear in the 'feature' directory before SHAP.py is run

## Limitations

- Interpretation is restricted to the motif-module input features, which come only from the HOCOMOCO Human v11 database PWMs and p-value threshold scores; motifs outside that collection cannot be assessed
- Results depend on the pre-trained models on eight cell lines and the environment specified in requirements.txt (Python 3.8, pip 23.3.1, tensorflow 2.2.0, scikit-learn, numpy); version mismatches may break SHAP.py
- Motif rankings are cell-line specific, so findings on one cell line (e.g. BACH1 in HUVEC) should not be assumed to generalize to others
