# top-k-rank-cutoff-sensitivity-analysis

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Quantifies cross-method agreement among ranked transcriptional-regulator (TR) lists (BIT, BART, ChIP-Atlas, i-cisTarget, HOMER, WhichTF) by computing pairwise Jaccard indices of top-k TR sets at k = 10, 50, and 100, mirroring Supplementary Fig. 9 of the BIT paper.

## When to use

Use when comparing ranked TR lists from multiple TR-identification methods on the same epigenomic query region sets, to test whether top-ranked hits agree at top-k cutoffs (k = 10, 50, 100).

## When NOT to use

- The goal is accuracy benchmarking against known perturbed TRs (e.g., five perturbed TRs in bulk datasets) — use mean reciprocal rank (MRR) instead of Jaccard overlap.
- Only one method's ranked list is available — pairwise Jaccard requires at least two methods run on the same query region sets.
- The input is raw epigenomic peaks rather than already-computed ranked TR tables — peak processing (MACS2 peak calling, blacklist removal, DAR filtering) must happen first.

## Inputs

- Ranked TR tables (TR name plus rank/score) from BIT for TR perturbation-derived DARs and cancer-type-specific accessible region sets
- Ranked TR tables from BART2 for the same query region sets
- Ranked TR tables from ChIP-Atlas, i-cisTarget, HOMER, and WhichTF for the same query region sets
- Top-k cutoff values (k = 10, 50, 100)

## Outputs

- Method-by-method Jaccard similarity matrices for each k (10, 50, 100) and each region-set type, written to CSV
- Heatmap renderings of the similarity matrices mirroring Supplementary Fig. 9

## How to apply

Load the ranked TR tables generated by each method (BIT, BART2, ChIP-Atlas, i-cisTarget, HOMER, WhichTF) for the TR perturbation-derived DARs and cancer-type-specific accessible region sets. For each query region set and each top-k cutoff (k = 10, 50, 100), extract the set of top-k TR names per method and compute all pairwise Jaccard indices as |intersection| / |union|. Assemble the indices into method-by-method similarity matrices for each k and region-set type, write them to a CSV table, and render each matrix as a heatmap. Validate that the reproduced pairwise Jaccard values are generally low across methods, consistent with the paper's Supplementary Fig. 9, and that the sensitivity across k cutoffs reveals whether any agreement is robust beyond the very top of the rankings.

## Evaluation signals

- All pairwise Jaccard values are in [0, 1] and each method-by-method matrix is symmetric with a diagonal of exactly 1.0.
- Reproduced pairwise Jaccard values are generally low across the six methods, consistent with the paper's report that 'Jaccard similarity among these approaches is generally low (Supplementary Fig. 9)'.
- One similarity matrix is produced per cutoff (k = 10, 50, 100) and per region-set type (TR perturbation-derived DARs and cancer-type-specific accessible regions).
- Each CSV table contains a 6x6 method-by-method matrix with rows/columns labeled BIT, BART2, ChIP-Atlas, i-cisTarget, HOMER, WhichTF.

## Limitations

- The validation target, Supplementary Fig. 9, is not included in the provided article text, so exact expected Jaccard values cannot be cross-checked from context.
- Low Jaccard similarity among methods means high disagreement; agreement at small k may not hold at larger k, so all three cutoffs should be reported rather than a single one.
- The comparison reflects method-level differences (Bayesian BIT vs. frequentist ChIP-seq- and motif-based approaches) as much as biological signal, so low overlap should not be interpreted as method failure without the MRR benchmark.
