# f-test-feature-selection

## Summary

Selects cell-type-specific genes as model features by applying an F-test to the reference scATAC-seq gene score matrix (produced by the ArchR pipeline), ranking genes by F-statistic and retaining the top 3000 for Cellcano's supervised celltyping models.

## When to use

Use when a reference scATAC-seq gene score matrix with known cell type labels must be reduced to informative, cell-type-specific genes before training a supervised celltyping model.

## When NOT to use

- Input is already a reduced feature table or pre-selected gene set rather than a full gene score matrix
- There are no annotated cell type labels for the reference data — the F-test requires groups to test gene-score differences against
- Celltyping will use bin counts as input instead of gene scores

## Inputs

- Reference scATAC-seq gene score matrix (from the ArchR pipeline)
- Metadata file with known cell type labels for reference cells

## Outputs

- selected_features.csv containing exactly 3000 selected cell-type-specific gene identifiers
- Filtered reference gene score matrix restricted to the top 3000 F-test genes (input to model construction)

## How to apply

Load the reference gene score matrix (obtained via the ArchR pipeline) together with its metadata file containing known cell type labels. Apply an F-test to each gene in the reference gene score matrix, testing for differences in gene scores across the annotated cell type labels, as implemented in Cellcano's feature-selection step. Rank all genes by their F-statistic in descending order and retain the top 3000 genes as the cell-type-specific feature set. Write the selected features to 'selected_features.csv' for use in constructing the first-round MLP and downstream Knowledge Distiller models. The rationale is that supervised celltyping on gene scores performs at least as well as on bin counts, so restricting input to discriminative genes improves efficiency without sacrificing accuracy.

## Evaluation signals

- 'selected_features.csv' exists in the output directory and contains exactly 3000 gene rows
- The file includes the required gene identifier field with gene names matching those in the reference gene score matrix
- Genes in the output are those with the highest F-statistics when testing gene scores across the annotated cell type labels
- The downstream first-round MLP trains successfully on the reduced reference matrix without feature-mismatch errors against target gene scores

## Limitations

- Cellcano's feature selection assumes an scATAC-seq reference; adaptation to cross-modality references (e.g. scRNA-seq) is planned but not implemented
- Gene scores must first be generated by the ArchR pipeline, so raw fragment or bam inputs require that dependency
