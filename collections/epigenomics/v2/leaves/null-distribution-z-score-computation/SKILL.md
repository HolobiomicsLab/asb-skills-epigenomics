# null-distribution-z-score-computation

## Summary

Compute z scores measuring how far an observed genomic range overlap statistic (e.g., liver caQTL peaks overlapping total cholesterol GWAS SNPs) falls from a null distribution generated by segmented block bootstrap (bootRanges) versus conventional shuffling, revealing that shuffling produces overly narrow nulls and inflated significance.

## When to use

Use when testing enrichment of overlap between two genomic range sets (e.g., ATAC-seq caQTL peaks and GWAS SNPs) and you need to compare block-bootstrap vs. shuffling nulls via z scores of the overlap rate.

## When NOT to use

- When the analysis goal is optimizing DEG logFC thresholds via generalized splines on overlap counts (use the macrophage.R workflow instead)
- When comparing running time of bootRanges vs. GSC on genome-scale statistics (use bootranges_vs_GSC.R)

## Inputs

- GRanges object of human liver caQTL peaks
- GRanges object of total cholesterol GWAS SNPs
- Genome segmentation method(s) with block lengths Lb = 300 kb and 600 kb

## Outputs

- Overlap rate between observed and null range sets with its variance
- Z scores for segmented block bootstrap nulls (expected ~4) and conventional shuffling nulls (expected ~18.5)
- liver_chol_zscores.csv tabulating bootstrap vs. shuffling z scores across segmentation methods and block lengths

## How to apply

First construct GRanges objects for the two range sets (e.g., human liver caQTL peaks and total cholesterol SNPs) with GRanges_construct.R. Generate null range sets via bootRanges' segmented block bootstrap (segBootranges.R) using block lengths Lb = 300 kb and 600 kb over genome segmentation methods, then compute the overlap rate and its variance with var.R to derive z scores. In parallel, generate conventional (unsegmented) shuffling nulls with bootstrap.R and derive the shuffling-based z score for the same overlap statistic. Tabulate z scores across segmentation methods and block lengths (expected ~4 for block bootstrap vs. ~18.5 for shuffling) and write results to liver_chol_zscores.csv. The rationale is that shuffling ignores local genomic correlation structure, yielding an overly narrow null distribution and over-estimated significance, while block bootstrap preserves local structure for more reliable nulls.

## Related tools

- **bootRanges** (Generates segmented block bootstrapped null genomic ranges preserving local correlation structure for the overlap statistic) — https://bioconductor.org/packages/nullranges
- **nullranges** (R/Bioconductor package hosting bootRanges functions used to produce null range sets) — https://bioconductor.org/packages/nullranges

## Examples

```
Rscript segBootranges.R  # then Rscript var.R; Rscript bootstrap.R  (Wancen/bootRangespaper script/liver pipeline, block lengths Lb = 300 kb and 600 kb)
```

## Evaluation signals

- Segmented block bootstrap z score falls near ~4 across segmentation methods and block lengths (300 kb, 600 kb)
- Conventional shuffling z score is markedly inflated near ~18.5, confirming an overly narrow null distribution
- liver_chol_zscores.csv contains tabulated z scores for both null schemes across all segmentation methods and both block lengths
- Bootstrap null range sets are generated by segBootranges.R and shuffling nulls by bootstrap.R, with z scores derived in var.R as in the paper's scripts

## Limitations

- Conventional shuffling or permutation schemes may result in overly narrow test statistic null distributions and over-estimation of statistical significance
- Block length choice (300 kb vs. 600 kb) and genome segmentation method affect the resulting z scores and must be reported/tallied explicitly
