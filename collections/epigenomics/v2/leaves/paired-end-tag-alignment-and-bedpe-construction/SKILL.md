# paired-end-tag-alignment-and-bedpe-construction

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Align linker-trimmed paired-end ChIA-PET reads to a reference genome with bwa, form paired-end tags (PETs) from the two SAM files with ChIA-PET2's buildBedpe at a MAPQ cutoff of 30, then remove PCR duplicate PETs with removeDup before peak calling.

## When to use

Use when processing raw ChIA-PET paired-end FASTQ data after linker trimming and you need aligned PETs as deduplicated BEDPE pairs for downstream peak and loop calling.

## When NOT to use

- Input reads still contain linker sequences — trimLinker must run first, as untrimmed linkers corrupt alignment and PET pairing.
- Data were not generated by a ChIA-PET protocol requiring PET construction (e.g. plain ChIP-Seq or Hi-C data that does not use BEDPE PET representation).

## Inputs

- linker-trimmed paired-end FASTQ(.gz) reads (output of trimLinker)
- reference genome index for bwa
- two SAM files from bwa alignment of read1 and read2

## Outputs

- BEDPE file of paired-end tags (PETs) passing MAPQ >= 30
- deduplicated BEDPE file after PCR duplicate removal with removeDup

## How to apply

After trimLinker produces trimmed FASTQ reads (minimum trimmed read length 15, zero linker mismatches, keep-empty=0), align each end independently with bwa to the reference genome, yielding two SAM files. Feed both SAM files to ChIA-PET2's buildBedpe, which pairs the aligned mates into BEDPE records while applying a MAPQ cutoff of 30 to discard ambiguously mapped PETs. Pass the BEDPE to removeDup to collapse PCR duplicate PETs (multithreaded via -N), since duplicated ligation products inflate PET counts and bias loop significance. The rationale is that only uniquely and confidently mapped, deduplicated PET pairs should feed buildTagAlign, MACS2 anchor peak calling and bedpe2Interaction loop detection.

## Related tools

- **bwa** (aligns linker-trimmed paired-end reads to the reference genome, producing the two SAM files used for PET construction) — https://github.com/lh3/bwa
- **ChIA-PET2** (provides buildBedpe (builds BEDPE from two SAM files at MAPQ cutoff 30) and removeDup (removes duplicate PETs with N threads)) — https://github.com/GuipengLi/ChIA-PET2
- **samtools** (handles SAM file manipulation required downstream of bwa alignment) — https://github.com/samtools/samtools
- **bedtools** (bed/bedpe file manipulation for downstream processing of the constructed BEDPE) — https://github.com/arq5x/bedtools2

## Examples

```
ChIA-PET2 buildBedpe -S read1.sam -S read2.sam -o pets.bedpe -q 30 && ChIA-PET2 removeDup -b pets.bedpe -o pets.dedup.bedpe -N 8
```

## Evaluation signals

- BEDPE output exists and each record has paired genomic coordinates for both ends of the PET.
- All retained PETs have MAPQ >= 30 in both mates (buildBedpe cutoff).
- PCR duplicate PET count is reduced after removeDup; deduplicated BEDPE is the input expected by buildTagAlign.
- Downstream sanity check: buildTagAlign on the deduplicated BEDPE yields a tagAlign file that MACS2 can use for anchor peak calling at q-value 0.05.
- PET counts at each step (aligned, bedpe-built, deduplicated) are monotonically non-increasing.

## Limitations

- MAPQ cutoff of 30 discards ambiguously or repetitively mapped PETs, which may drop genuine interactions in repetitive regions.
- PCR duplicate removal assumes the deduplication correctly distinguishes true biological duplicates from library PCR artifacts.
- Loop calling quality depends on peak-calling sensitivity at the anchor step, and no versions were stated for bwa, samtools, bedtools or MACS2 in the article.
