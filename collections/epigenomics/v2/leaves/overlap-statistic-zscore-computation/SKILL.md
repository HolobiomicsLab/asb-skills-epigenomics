# overlap-statistic-zscore-computation

## Summary

Computes the rate of overlap between two genomic range sets (e.g. null-bootstrapped ranges and observed ranges), its variance across null iterations, and a z-score statistic, as implemented in var.R from the bootRanges paper. This statistic is what allows calibrated (bootRanges block bootstrap) vs over-narrow (shuffling) null distributions to be compared at a nominal alpha threshold.

## When to use

Use when a set of null genomic range iterations (from bootRanges block bootstrap or conventional shuffling) must be converted into an overlap-rate statistic with variance and z-score for false-positive-rate or significance assessment.

## When NOT to use

- The goal is generating the null range sets themselves rather than scoring them — use bootRanges (segBootranges.R) or bootstrap.R first; this skill only computes the overlap-rate statistic.
- The analysis requires overlap counts for threshold optimization (e.g. DEG logFC thresholds with generalized splines in macrophage.R) rather than overlap-rate variance/z-score significance testing.
- Input is not genomic ranges or the comparison target lacks a defined overlap definition (e.g. continuous genome-scale statistics compared for running time in bootranges_vs_GSC.R).

## Inputs

- Null genomic range sets (GRanges) per iteration, generated by bootRanges block bootstrap (segBootranges.R) or conventional shuffling (bootstrap.R)
- Observed genomic range set y (e.g. caQTL SNPs associated with total cholesterol in human liver tissue, or simulated ranges with no true association to x)

## Outputs

- Per-iteration overlap rate between null x and y
- Variance of the rate of overlaps and z-score statistic (var.R output)
- FPR table per method at nominal alpha (e.g. fpr_simulation_results.csv)

## How to apply

For each null iteration, take the bootstrapped or shuffled null range set for x and compute the overlap rate against the observed range set y. Aggregate the per-iteration overlap rates to estimate the variance of the rate of overlaps, following var.R from the bootRangespaper repository, and convert to a z-score statistic. Use the same variance and z-score computation for both null generation schemes (segBootranges.R block bootstrap and bootstrap.R conventional shuffling) so their null distributions are directly comparable. The key decision point is interpreting the z-score against the nominal significance threshold alpha: a null distribution with similar mean but much lower variance (typical of shuffling) yields elevated z-scores and over-estimated significance, whereas bootRanges block bootstrap preserves local genomic correlation structure and gives FPR near alpha. Tabulate the resulting FPR per method (e.g. fpr_simulation_results.csv) and accept the comparison if bootRanges FPR is close to alpha while the shuffling-based FPR is clearly elevated.

## Evaluation signals

- Per-iteration overlap rates are defined for every null iteration and the variance is computed across the same iteration set used for both bootRanges and shuffling schemes.
- In the no-association simulation, the bootRanges-based FPR at threshold alpha should be close to the nominal alpha (correct calibration).
- The shuffling-based null distribution should show a similar mean but much lower variance than the bootRanges null, producing a clearly elevated FPR above alpha.
- Output tabulation (fpr_simulation_results.csv) contains FPR rows for both bootRanges and shuffling methods, enabling a direct side-by-side calibration check.

## Limitations

- Shuffling or permutation-based nulls can yield overly narrow test statistic null distributions and over-estimation of statistical significance, so z-scores from conventional shuffling should not be treated as calibrated.
- The block bootstrap's calibration depends on preserving local genomic correlation structure; this statistic alone does not fix poorly constructed null ranges.
- The statistic is defined on the rate of overlaps between range sets; applications needing overlap counts or correlation summaries (macrophage.R, multiomicsCor.R) fall outside this skill.
