# short-range-chromatin-loop-verification

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Detects and validates short-range (<8 kb) CTCF-mediated chromatin loops from ChIA-PET data using the ChIA-PET2 pipeline with the empirical 8 kb self-ligation span filter removed, including MICC2.R statistical significance calling and anchor-level ChIP-seq validation (e.g. the ~1.6 kb MYC loop).

## When to use

Use when a ChIA-PET dataset (e.g. GM12878 CTCF paired-end FASTQ) must be analyzed for very short-range (<8 kb) chromatin loops that standard pipelines miss due to self-ligation span cutoffs.

## When NOT to use

- Input data was generated by a half-linker ChIA-PET protocol and you intend to use Mango-specific assumptions; ChIA-PET2 supports both, but Mango was reported too conservative at significant loop calling
- The analysis goal is allele-specific chromatin interaction calling rather than short-range loop detection
- Only long-range (>8 kb) loops are of interest and the default self-ligation cutoff is acceptable — removing the span filter will admit many short-range self-ligation events you would then discard

## Inputs

- Paired-end ChIA-PET FASTQ reads (e.g. GM12878 CTCF ChIA-PET, GSE72816/GSM970213)
- Reference genome index for bwa
- CTCF, RAD21 and SMC3 ChIP-seq peak/BED files (e.g. from ENCODE) for anchor validation

## Outputs

- Deduplicated PET bedpe file (MAPQ >= 30)
- MACS2 anchor peaks (q-value 0.05) in bed format
- MICC2.R output table with 13 columns including PET counts, -log10(1-PostProbability) and FDR per loop
- Filtered list of significant short-range (<8 kb) CTCF-mediated loops with per-loop genomic span and PET support

## How to apply

Run the ChIA-PET2 pipeline starting from paired-end FASTQ reads: trim linkers with trimLinker (mismatch=0, min trimmed read length=15, keep-empty=0), align with bwa, build PETs with buildBedpe at MAPQ 30, and remove PCR duplicates with removeDup. Convert the deduplicated bedpe to tagAlign (buildTagAlign), call anchor peaks with MACS2 at q-value 0.05, then detect interactions with bedpe2Interaction (pairToBed -type both) WITHOUT imposing the 8 kb self-ligation span filter — this is the critical decision point enabling short-range loop recovery. Estimate loop significance with MICC2.R using a PET count cutoff of 2, which yields per-loop -log10(1-PostProbability) and FDR columns from the Bayesian mixture model. Filter the significant loops to genomic span <8 kb, count them (expected ~2,893 in the GM12878 CTCF dataset), and validate biologically by confirming anchor overlap with CTCF/RAD21/SMC3 ChIP-seq occupancy (e.g. the ~1.6 kb MYC-locus loop supported by 30 PETs).

## Examples

```
MICC2.R -i pet.clusters.txt -f peaks.bed -o micc.out --CUTOFFPET 2; awk '$6-$2<8000 && $12<0.05' micc.out
```

## Evaluation signals

- MICC output file exists with the expected 13-column format including PET count, -log10(1-PostProbability) and FDR columns
- Total count of significant loops with genomic span <8 kb equals 2,893 for the GM12878 CTCF dataset
- The output contains the ~1.6 kb loop near the MYC locus supported by 30 PETs
- The MYC short-range loop anchors overlap CTCF/RAD21/SMC3 ChIP-seq occupancy
- Intermediate bedpe is deduplicated (removeDup run) and PETs pass MAPQ cutoff 30

## Limitations

- Extremely short-range chromatin loops (<8 kb) could not be detected by previous ChIA-PET pipelines due to methodology limitation — results are only comparable to pipelines run without the span filter
- Loop calling depends on ChIP-Seq-like peak calling sensitivity; loops whose anchors fall outside called peaks are missed
- No software version stated for ChIA-PET2 or its dependencies (bwa, samtools, bedtools, MACS2, g++), complicating exact reproduction
- MICC2.R uses a default PET count cutoff of 2; different thresholds trade off sensitivity and specificity of loop calling
