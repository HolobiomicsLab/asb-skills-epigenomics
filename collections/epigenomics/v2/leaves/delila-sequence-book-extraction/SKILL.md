# delila-sequence-book-extraction

## Summary

Reconstructs the Delila-PY GenBank-to-book preprocessing stage: dbbk and catal convert the GenBank record for the genome of interest (e.g., R. sphaeroides chromosome NC_007493.2) into Delila libraries, and the delila program then uses those libraries plus a tab-delimited genomic position file to emit the book of sequences consumed by the downstream motif cycles (malign/malin, ri, makelogo).

## When to use

Use when a Delila-PY run must go from a raw NCBI GenBank file plus a four-column tab-delimited sites file (chromosome, name, strand, base-pair position) to the delila-generated book of sequences, or when validating that book before motif cycling.

## When NOT to use

- The input is already an extracted, aligned set of sequences (e.g., a sites FASTA) — no GenBank record or coordinate extraction is needed, so the dbbk/catal/delila stage is unnecessary.
- Coordinates are supplied as start-end intervals (e.g., GFF/BED) rather than a single base-pair position per row; the Delila-PY sites file expects one four-column chromosome/name/strand/position record per site.
- No GenBank file exists for the genome of interest, since the libraries used by delila must first be generated from the GenBank file by dbbk and catal.

## Inputs

- NCBI GenBank file for the genome of interest (e.g., Rsphaeroides_GenBank.gbff for R. sphaeroides chromosome NC_007493.2)
- Tab-delimited genomic position (sites) file with four columns and no column names: chromosome name, unique site name, strand (forward/reverse), base-pair position
- User-specified left and right boundary distances (-l, -r) relative to each site position on the given strand

## Outputs

- Delila database libraries generated from the GenBank record by dbbk, plus the required catalyzed libraries generated by catal
- Book of sequences emitted by the delila program, containing one extracted sequence entry per row of the position file, for use by the malign/malin, ri, and makelogo cycles

## How to apply

Prepare the two required inputs: the NCBI GenBank file for the genome of interest (e.g., Rsphaeroides_GenBank.gbff for R. sphaeroides chromosome NC_007493.2) and a tab-delimited sites file with exactly four columns and no column names — chromosome name (must match the chromosome names in the GenBank file), a unique site name, strand written literally as 'forward' or 'reverse', and base-pair position (e.g., 'NC_007493.2 site_1 forward 409225'). Define the script directory by editing the scriptDir variable in delila_pipeline.py before running. Invoke delila_pipeline.py with -g (GenBank file), -s (sites file), and -l/-r boundary distances interpreted on each site's strand relative to the position — e.g., Left=-10/Right=+10 spans positions 90-110 for a site at 100, while searching a -35 promoter element upstream of a transcription start site uses Left=+5/Right=+25. The pipeline first runs dbbk on the GenBank file to process the genome record into Delila database libraries, then catal to generate the required catalyzed libraries; delila then consumes the library and genomic position files to extract the bounded sequences and emit the book of sequences. Prefer the recommended glbrc/delila Docker image with a mounted data volume (container working directory /opt/delila/example/container-data), or download and compile the individual Delila programs locally (p2c provides the Pascal-to-C translation). Validate the book — exactly one sequence entry per row of the position file and the chromosome name NC_007493.2 present in the extracted records — before feeding cycle 1, where malign and malin search for the alignment with the highest information content among all input sequences.

## Examples

```
delila_pipeline.py -g Rsphaeroides_GenBank.gbff -l -10 -r -10 -s Location_File_Example.txt -t "Logo Title"
```

## Evaluation signals

- The book contains exactly one sequence entry per row of the genomic position (sites) file.
- The chromosome name NC_007493.2 (or the target chromosome) is present in the extracted sequence records.
- Extracted window widths match the -l/-r boundaries: a site at position 100 with Left=-10 and Right=+10 spans positions 90-110.
- Every sites-file chromosome string resolves against a chromosome name in the GenBank file, so delila extracts all requested sites without unresolved names.
- The book is consumable by cycle 1, where malign and malin search for the alignment with the highest information content among all input sequences.

## Limitations

- Chromosome names in the sites file must match the chromosome names in the GenBank file, and the strand must use the literal words 'forward' or 'reverse'.
- Left and right boundaries are always interpreted on the given strand, so sign conventions differ per scenario (e.g., a -35 element upstream of a transcription start site uses Left=+5, Right=+25).
- The scriptDir variable in delila_pipeline.py must be edited to define the script directory before running.
- Delila-PY has been tested on MacOS and Linux (Ubuntu and CentOS); other operating systems may require additional work.
