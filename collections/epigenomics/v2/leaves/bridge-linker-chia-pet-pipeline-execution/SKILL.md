# bridge-linker-chia-pet-pipeline-execution

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Executes the ChIA-PET2 pipeline in bridge-linker mode (-m 1) from raw paired-end FASTQ reads through linker trimming, bwa alignment, PET construction, duplicate removal, and interaction detection, producing stepwise statistics and QC plots for datasets like GM12878 CTCF.

## When to use

Use when processing bridge-linker ChIA-PET FASTQ data from raw reads to chromatin loops, or when reproducing stepwise PET retention statistics and QC figures for a ChIA-PET dataset.

## When NOT to use

- Input is half-linker ChIA-PET data — use the half-linker mode/protocol instead of bridge-linker mode (-m 1)
- The analysis goal is only significant loop calling (e.g. ChiaSig or MICC) without processing raw sequencing reads
- The dataset was generated by a protocol incompatible with the bridge-linker ChIA-PET format

## Inputs

- Bridge-linker ChIA-PET paired-end FASTQ files (fastq or fastq.gz)
- Reference genome index for bwa alignment
- Phased genotype data (optional, for allele-specific chromatin interactions)

## Outputs

- prefixname.trim.stat (linker trimming statistics)
- prefixname_1.valid.sam (aligned valid PETs)
- prefixname.bedpe.stat (PET/duplicate statistics)
- Bedpe file of PETs for MACS2 peak calling input
- prefixname.QCplot.pdf (multi-panel quality-control figure)
- Significant chromatin loop calls (chromatin interactions)

## How to apply

Run the ChIA-PET2 pipeline steps 1-5 in bridge-linker mode (-m 1): trimLinker (with -l 15 minimum trimmed read length) to remove linker sequences from paired-end fastq(.gz) files, bwa alignment with a -Q 30 MAPQ cutoff, buildBedpe to construct bedpe files from the two SAM files, removeDup to remove duplicate PETs, and bedpe2Interaction to detect chromatin interactions. Each step generates statistics files (prefixname.trim.stat, prefixname_1.valid.sam, prefixname.bedpe.stat). Then invoke step 6 via 'Rscript QCplots.R directory name' so ggplot2 aggregates the stepwise statistics into a multi-panel quality-control figure. Compute the stepwise fractions — valid PETs pre-alignment (89.95%), post-alignment (85%), post-duplicate-removal (41.08% for MACS2 peak calling input), and intra-chromosomal interactions supported by >=4 PETs (92.12%) — and verify prefixname.QCplot.pdf is produced with matching values.

- Intra-chromosomal interactions supported by >=4 PETs reproduces 92.12%

## Limitations

- ChIA-PET2 calls chromatin loops based on ChIP-Seq-like peaks, assuming loop anchors are located at ChIP-Seq-like peaks; loop calling depends on peak calling sensitivity
- No software version of ChIA-PET2 stated, and no versions stated for required dependencies (bwa, samtools, bedtools, MACS2, g++)
- Users must choose different thresholds to balance the trade-off between sensitivity and specificity of chromatin loop calling
