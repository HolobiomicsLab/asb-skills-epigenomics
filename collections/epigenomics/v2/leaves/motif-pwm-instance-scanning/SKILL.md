# motif-pwm-instance-scanning

## Summary

Scans genomic or designed sequences against a curated position weight matrix (PWM) library (e.g., gimme.vertebrate.v5.0.meme) with FIMO to enumerate concrete TF motif instances per sequence. In the BOM workflow this supplies both the motif-count features for XGBoost training and the concrete motif sequences implanted into synthetic regulatory elements (SREs).

## When to use

Use when you have genomic FASTA sequences (e.g., ATAC-derived distal elements) plus a PWM file such as gimme.vertebrate.v5.0.meme and need per-sequence motif instances/counts for downstream modeling or SRE construction.

## When NOT to use

- Your regulatory model must capture motif order, spacing, or grammar — BOM's representation is explicitly unordered and motif-grammar integration is an unfinished future direction
- The TF motifs of interest are absent from the current motif annotations, since the reliance on known TF motifs neglects informative sequences not captured by current motif annotations
- You need to account for open chromatin, histone marks, or trans-acting context — BOM is constrained to cis-regulatory information within the input sequence

## Inputs

- FASTA file of regulatory element sequences generated by generateAllFasta() from a chromosome/start/stop/condition input file and a BSgenome reference (e.g., BSgenome.Mmusculus.UCSC.mm10)
- PWM motif library in MEME format (gimme.vertebrate.v5.0.meme, bundled in BOM_package extdata)
- Installed FIMO binary (MEME Suite) with its filesystem path
- For SRE design: per-condition SHAP-ranked top-5 motifs (from save_shap_multi()) and a template enhancer sequence with coordinates (e.g., chr2:211,153,192-211,153,452)

## Outputs

- FIMO motif annotation hits per input sequence (positions, PWM matches, orientation)
- Per-sequence unordered motif count matrix used as XGBoost features by binModel()
- Concrete motif nucleotide sequences matched from PWMs for implantation into designed_SREs.fasta

## How to apply

First generate the query FASTA from genomic intervals via generateAllFasta(), passing a BED-like input (chromosome, start, stop, condition) and a BSgenome object (e.g., BSgenome.Mmusculus.UCSC.mm10). Then run FIMO against the bundled motif library by supplying motifs_path pointing to gimme.vertebrate.v5.0.meme and the local FIMO binary path, producing motif annotations for every input sequence. The resulting per-sequence motif hits are aggregated into unordered motif counts (the bag-of-motifs representation, independent of motif order, orientation, or spacing) that binModel() turns into XGBoost training features. When constructing synthetic regulatory elements, the same PWM file is used FIMO-style to match each top-5 SHAP-ranked motif (per condition, e.g., HepG2 or GM12878) to a concrete nucleotide sequence, which is then implanted as two copies at random positions in a template backbone such as the 260 bp muscle enhancer at chr2:211,153,192-211,153,452. The scanning step is deliberately separate from model training so PWM version and scanning parameters are fixed before any SHAP-based motif ranking.

## Examples

```
BagOfMotifs::runFIMO(motifs_path = motifs_path, FIMO_path = FIMO_path)
```

## Evaluation signals

- runFIMO() completes without error against the specified motifs_path (gimme.vertebrate.v5.0.meme) and FIMO binary, producing motif annotations for every record in the generateAllFasta() output
- The motif-count matrix contains counts per sequence that are orientation- and position-agnostic (two sequences with identical motif composition yield identical feature rows)
- For SRE design, designed_SREs.fasta exists in valid FASTA format and contains exactly 11 records (10 SREs plus the unmodified 260 bp template)
- Each designed SRE sequence contains two instances of each of its five assigned top-5 SHAP-ranked motifs, verifiable by re-scanning the SREs with the same PWM library
- The template backbone (chr2:211,153,192-211,153,452, 260 bp) is recoverable from the reference genome at the specified coordinates and differs from SREs only by implanted motif copies

## Limitations

- The reliance on known TF motifs neglects informative sequences not captured by current motif annotations
- TFs do not bind all their motifs, so PWM hits are imperfect proxies for binding
- BOM is constrained to cis-regulatory information within the input sequence; open chromatin status, histone marks, and enhancer activity can be influenced by regions beyond the sequence length used
