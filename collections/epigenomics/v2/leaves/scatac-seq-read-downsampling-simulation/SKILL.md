# scatac-seq-read-downsampling-simulation

## Summary

Benchmark clustering robustness on simulated scATAC-seq datasets generated by downsampling 10 published bulk ATAC-seq datasets to 1,000–10,000 reads per cell, scoring cell-type recovery with ARI and NMI. It exists to show which method (SnapATAC vs LSA vs cisTopic) remains accurate at varying coverage.

## When to use

Use when evaluating scATAC-seq clustering methods for coverage robustness: simulated datasets at graded depths (1,000–10,000 reads/cell) are needed and cell-type recovery is quantified by ARI/NMI against reference labels.

## When NOT to use

- Input is real scATAC-seq data with native coverage rather than simulated downsampled profiles — this skill only benchmarks coverage robustness on simulated data
- Only a single coverage depth is available, so robustness-vs-coverage trends and the ARI/NMI comparison across the 1,000–10,000 reads/cell range cannot be computed

## Inputs

- 10X_PBMC_15K scATAC-seq snap dataset (snap file with cell-by-bin matrices)
- 10 published bulk ATAC-seq datasets used as downsampling sources
- Reference (ground-truth) cell-type labels per simulated cell

## Outputs

- ari_nmi_comparison.csv with one row per (method, coverage level) pair
- Per-coverage cluster assignments from SnapATAC, LSA, and cisTopic
- ARI and NMI scores at each of the 1,000–10,000 reads/cell coverage levels

## How to apply

Install SnapATAC with devtools install_github("r3fang/SnapATAC") under R >= 3.4.0 and < 3.6.0 (R 3.6 fails with the rhdf5 package) and SnapTools under Python 2.7 for preprocessing. Load the 10X_PBMC_15K example snap dataset and generate simulated coverage variants by downsampling to 1,000–10,000 reads per cell. For each coverage level run the SnapATAC pipeline (makeBinary on the bin matrix, runDimReduct with the specified pc.num, Leiden clustering via runCluster with tmp.folder, louvain.lib, resolution, seed.use), then run the LSA comparator via runLSA(obj, input.mat, pc.num, logTF, scale.factor, min.cell, seed.use) with the same Leiden clustering. Compute ARI and NMI of each method's clusters against the original cell-type labels at every coverage, assemble one row per (method, coverage) into ari_nmi_comparison.csv, and compare against cisTopic.

## Evaluation signals

- SnapATAC attains the highest ARI and NMI across the full 1,000–10,000 reads/cell coverage range, matching the paper's claim of superior accuracy and reproducibility
- SnapATAC's ARI/NMI significantly outperform LSA and cisTopic under a Wilcoxon signed-rank test with p < 0.01
- ari_nmi_comparison.csv contains exactly one row per (method, coverage level) pair across all coverage levels
- Simulated datasets reproduce the original cell types identifiably at each downsampled depth, confirming downsampling did not destroy label structure

## Limitations

- R 3.6 does not work for the rhdf5 package, so SnapATAC requires R >= 3.4.0 & < 3.6.0, and SnapTools is highly recommended under Python 2.7
- Sparsity of scATAC-seq profiles (only 5–15% of peaks detected per cell) makes low-coverage simulations inherently noisy
- SnapATAC 1.x is superseded by SnapATAC2 (https://github.com/kaizhang/SnapATAC2, scverse/SnapATAC2), so this legacy pipeline is only appropriate for reproducing the original benchmark
