# adjusted-rand-index-computation

## Summary

Computes the adjusted Rand index (ARI) between hierarchical-cluster assignments on each method's reduced feature space and known ground-truth cell-line labels, used to benchmark ChromSCape (ARI 0.998) against Cusanovich2018, SnapATAC, CisTopic and EpiScanpy on an in-silico H3K27me3 four-cell-type scChIP-seq mix.

## When to use

Use when scoring clustering quality of single-cell epigenomic methods against known ground-truth cell labels (e.g. sorted cell lines), comparing methods such as ChromSCape, SnapATAC, CisTopic, Cusanovich2018 and EpiScanpy on a shared dataset.

## When NOT to use

- Cells have no known ground-truth labels (e.g. real tissue without sorted populations) — ARI against a reference partition cannot be computed.
- Input is a raw count matrix with no clustering or reduced feature space yet — this skill scores partitions; it does not cluster or reduce dimensions itself.
- Assessing continuous embeddings or pairwise cell similarities rather than agreement between two discrete partitions.

## Inputs

- In-silico H3K27me3 scChIP-seq count matrix (50kbp bins) for 1287 QC-passing cells from Jurkat, Ramos and HBCx-22 (GSE117309) and MDA-MB-468 (GSE152502)
- Reduced feature spaces / hierarchical-cluster assignments from each method (ChromSCape 50-PC PCA, Cusanovich2018, SnapATAC, CisTopic, EpiScanpy)
- Ground-truth cell-line labels (Jurkat, Ramos, HBCx-22, MDA-MB-468) for each of the 1287 cells

## Outputs

- Adjusted Rand index per method (expected ~0.998 ChromSCape, 0.996 Cusanovich2018, 0.822 SnapATAC, 0.996 CisTopic, 0.940 EpiScanpy)
- ari_results.csv summarizing the five recomputed ARI values
- Benchmark figures (Figures 2a and 2b) regenerated by cross_analysis.R

## How to apply

Run every method on the identical in-silico H3K27me3 count matrix of 1287 QC-passing cells mixing Jurkat, Ramos, HBCx-22 and MDA-MB-468: ChromSCape with default settings (QC filtering, count normalization, PCA keeping the first 50 PCs), Cusanovich2018 and CisTopic (requiring merged_peaks.5000.bed pseudo-bulk peaks) via the pinellolab/scATAC-benchmarking scripts, SnapATAC on 50kbp genomic bins, and EpiScanpy following its scATAC-seq tutorial. Apply hierarchical clustering to each method's reduced feature space, then compute the adjusted Rand index between the resulting cluster assignments and the known cell-line labels. ARI is chance-adjusted, so near-1 values (ChromSCape 0.998, Cusanovich2018/CisTopic 0.996, EpiScanpy 0.940) indicate near-perfect cell-type separation, while SnapATAC's 0.822 reflects its coarser 50kbp binning. Collect all five values into ari_results.csv and accept each recomputed ARI only if it falls within ±0.05 of the published value. The cross_analysis.R script in vallotlab/ChromSCape_benchmarking regenerates Figures 2a and 2b from these scores.

## Evaluation signals

- Each recomputed ARI matches the published value within ±0.05: ChromSCape 0.998, Cusanovich2018 0.996, SnapATAC 0.822, CisTopic 0.996, EpiScanpy 0.940.
- ari_results.csv contains exactly five method-level ARI values, all within the [0,1] range.
- All five methods were scored on the same 1287 QC-passing cells with identical ground-truth cell-line labels.
- Randomly permuting cluster labels drives the ARI toward 0, confirming the index is chance-adjusted.
- cross_analysis.R from vallotlab/ChromSCape_benchmarking reproduces Figures 2a and 2b from the computed scores.

## Limitations

- Benchmark restricted to 1287 QC-passing cells with random sub-sampling of 500 MDA-MB-468 cells, a potentially limiting comparison scope.
- Known copy-number-aberrant regions of MDA-MB-468 (77 Mbp, MM468_identified_CNA.bed) had to be removed beforehand, an extra manual curation step affecting comparability.
- SnapATAC was evaluated on coarse 50kbp bins, penalizing its ARI (0.822) relative to peak- or PC-level methods.
