# benchmark-method-comparison-reporting

## Summary

Reproduces the head-to-head 5-fold cross-validation comparison of csDMA (ExtraTrees, Motif+Kmer+Binary features) against the iDNA6mA-PseKNC baseline (SVM, C=0.336, gamma=0.02) on the cross-species, rice, and M. musculus DNA 6mA benchmarks, assembling the results into a Table-4-style CSV.

## When to use

Use when a new predictor must be benchmarked against an existing published tool under identical cross-validation on shared datasets (e.g. DNA 6mA site prediction) and the deliverable is a side-by-side metrics table.

## When NOT to use

- The goal is independent-test or jackknife evaluation rather than the paper's 5-fold cross-validation comparison (e.g. i6mA-Pred's ACC of 0.831 was reported by jackknife and is not directly comparable here).
- Only one dataset is available — the skill requires the shared cross-species, rice, and M. musculus benchmarks for the side-by-side comparison.

## Inputs

- Training positive and negative 41nt DNA sequence datasets for the cross-species (2,768 positive / 2,716 negative), rice (880/880), and M. musculus (1,934/1,934) benchmarks
- Motif feature score matrices (matrix_motif1, matrix_motif2) generated by feature_selection.py
- Baseline hyperparameters for the reimplemented iDNA6mA-PseKNC SVM (C=0.336, gamma=0.02)

## Outputs

- Per-dataset cross-validation metrics (AUC, ACC, Sn, Sp, MCC) for csDMA and iDNA6mA-PseKNC
- Comparison table saved as table4_cross_validation_results.csv mirroring the paper's Table 4

## How to apply

Load the training positive and negative FASTA sequence sets for all three benchmarks with pandas/biopython, then generate the Motif + Kmer + Binary feature score matrices (matrix_motif1, matrix_motif2) via feature_selection.py so both predictors see identical encodings. Run 5-fold cross-validation of csDMA built on the ExtraTrees classifier over each dataset's feature matrix, and separately run 5-fold cross-validation of the reimplemented iDNA6mA-PseKNC baseline using an SVM with C=0.336 and gamma=0.02. Compute per-dataset AUC, ACC, Sn, Sp, and MCC from the cross-validation score files for both predictors. Assemble the metrics side-by-side into a table mirroring Table 4 (csDMA AUC 0.879/0.923/0.965 vs iDNA6mA-PseKNC 0.844/0.896/0.974 on cross-species/rice/M. musculus) and save it as table4_cross_validation_results.csv. Judgement of success: the csDMA AUC reproduces ~0.879 (cross-species) and ~0.923 (rice), exceeding the baseline, while honestly reporting that iDNA6mA-PseKNC retains a higher AUC on M. musculus (0.974 vs 0.965).

## Evaluation signals

- csDMA cross-validation AUC falls near 0.879 on the cross-species dataset and 0.923 on the rice dataset, higher than iDNA6mA-PseKNC's 0.844 and 0.896
- The M. musculus row reproduces iDNA6mA-PseKNC's higher AUC (0.974 vs csDMA 0.965) — the table must not silently flip this result
- Both predictors are scored on identical feature matrices (matrix_motif1, matrix_motif2) from feature_selection.py, so any AUC difference is attributable to the classifier, not the encoding
- Output CSV contains AUC, ACC, Sn, Sp, MCC columns for each of the three datasets and both predictors
- The comparison is based on 5-fold cross-validation, not independent testing, matching Table 4's evaluation protocol

## Limitations

- i6mA-Pred could not be directly compared: the paper was still in corrected proof phase and the method was unreachable, so its ACC of 0.831 was known only from the online abstract via a jackknife test.
- csDMA performance was relatively low on the rice and cross-species datasets compared to M. musculus, and the baseline remains superior on M. musculus.
- csDMA was implemented in Python 2.7, which may complicate reproduction in modern environments.
