# pie-chart-distribution-visualization

## Summary

Annotate a set of genomic intervals (e.g. MACS-called ChIP-seq peaks) to genomic features (promoter, intragenic, intergenic) using the SeqCode genomeDistribution command and visualize the resulting counts as pie-chart feature distributions via the R scripts emitted in the output folder.

## When to use

Use when you have BED-format peak lists or genomic coordinate sets (e.g. bivalent vs single-mark ChIP-seq peaks) and need to quantify which genomic features they occupy and plot the distribution as pie charts.

## When NOT to use

- Input is raw sequencing reads (BAM/SAM) rather than already-called peak/interval coordinates — use read mapping and peak calling first
- You need genome-wide signal profiles in bigWig format — SeqCode does not support bigWig generation and defers it to future versions
- You need a plot type other than feature-distribution charts (e.g. TSS meta-plots or heatmaps) — use produceTSSplots/produceTSSmaps instead

## Inputs

- BED-formatted peak lists from MACS peak calling (e.g. bivalent, H3K4me3-only, H3K27me3-only peaks)
- Chromosome size file (chromInfo.txt) for the target genome assembly (e.g. mouse mm9)
- RefSeq gene transcript annotation file (refGene.txt) from the UCSC genome browser

## Outputs

- Per-peak genomic feature assignments (promoter, intergenic, intragenic)
- Aggregated per-class feature counts
- Pie-chart plots of the peak genomic distribution (PDF/images) generated by R scripts stored in the output folder

## How to apply

Provide SeqCode's genomeDistribution command with two genome-specific files retrieved from the UCSC genome browser downloads: the chromosome size file (chromInfo.txt) and the RefSeq transcript annotation (refGene.txt) for the assembly being analyzed (e.g. mouse mm9). Run the command on each BED peak list — for example bivalent (H3K4me3+H3K27me3), H3K4me3-only, and H3K27me3-only peaks — so every peak is assigned to promoter, intergenic, or intragenic features. GenomeDistribution creates a new output folder containing the data files plus R scripts; run these R scripts to generate the pie-chart plots of the per-class feature counts. Finally, aggregate the per-class counts and compare the charts across peak classes: a biologically correct run reproduces the expected pattern in which bivalent peaks are preferentially enriched in promoters relative to single-mark peaks.

## Related tools

- **SeqCode** (genomeDistribution command assigns each peak to promoter/intergenic/intragenic features and emits R scripts that generate the pie-chart plots) — https://github.com/eblancoga/seqcode
- **R** (internally executes the graphical scripts stored in the genomeDistribution output folder to produce the pie charts)

## Examples

```
bin/genomeDistribution ChromInfo.txt refGene.txt bivalent_peaks.bed bivalent_out; R CMD BATCH bivalent_out/Rscript.txt
```

## Evaluation signals

- Every input peak receives exactly one feature assignment (promoter, intergenic, or intragenic) with no peaks dropped
- Output folder contains the data files plus the R scripts used to generate the plots
- Resulting pie charts reproduce the expected Fig. 5b pattern: bivalent (H3K4me3+H3K27me3) peaks preferentially in gene promoters relative to single-mark peak classes
- Fraction of peaks in intergenic regions is minor for the bivalent class, matching the reported finding
- chromInfo.txt and refGene.txt files match the correct genome assembly (e.g. mm9) used for the peak coordinates

## Limitations

- SeqCode relies on RefSeq reference annotations, so feature categories are limited to what refGene.txt provides for the chosen assembly
- The web server is intended as a teaching resource with file-size restrictions; large peak sets require the command-line release
- Graphical representations of the same data can differ across existing programs, so pie-chart layouts may not be identical to those from other tools
