# beta-binomial-enriched-window-testing

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Statistical framework in Skipper that tests read-start enrichment in fixed windows tiled over annotated transcripts against matched input controls using a beta-binomial model, skipping peak calling entirely and reporting reproducible enriched windows as candidate RBP binding sites in eCLIP data.

## When to use

Use when analyzing eCLIP/CLIP-seq FASTQs that have matched input controls and at least 2 CLIP replicates, and you need reproducible, annotated binding-site windows rather than peak calls.

## When NOT to use

- The CLIP experiment lacks a matched input sample — the beta-binomial model cannot be constructed, so the analysis cannot be run at all
- Only a single CLIP replicate is available, since reproducible enriched windows require replication across at least 2 CLIP replicates
- The goal is peak-style binding coordinates rather than tiled transcript-window enrichment statistics, or the signal is expected outside annotated transcript windows (peak calling approaches are what Skipper intentionally replaces)

## Inputs

- Matched CLIP and input FASTQs (minimum 2 CLIP replicates per sample) listed in a manifest CSV
- Human genome FASTA (GRCh38.primary_assembly.genome.fa, GENCODE release 49)
- Filtered GFF annotation (gencode.v49.basic.annotation.gff3.gz processed with gff_transcript_quality_filter.R)
- Skipper_config.yaml with WORKDIR, PROTOCOL (ENCODE3/ENCODE4), UMI_SIZE, GINI_CUTOFF, and THRESHOLD_MIN
- STAR genome index (auto-generated by the pipeline)

## Outputs

- reproducible_enriched_windows file with statistics for significantly enriched windows found in all replicates
- reproducible_enriched_re (repeat element) results for bound annotated repetitive elements
- Fine-mapped enriched windows with feature annotations (introns, exons, UTRs)
- QC and multiqc reports

## How to apply

First partition a quality-filtered GFF (best transcript per gene, overlapping feature annotations resolved, tiled windows avoiding intron/exon boundary crossing) to define the windows to test. Then run the Skipper pipeline (Snakemake 9.12.0 with snakemake-executor-plugin-slurm 1.4.0 on SLURM) through preprocessing/trimming, STAR alignment, and enriched window identification, where read-start signal in each window is tested against the matched input sample via a beta-binomial model — this matched input is mandatory for model construction. Filter out narrow 'skyscraper' peaks using the GINI_CUTOFF parameter and threshold candidates with Flipper's THRESHOLD_MIN before fine-mapping and blacklisting user-specified regions. Reproducibility is assessed by requiring significant enrichment across all CLIP replicates, and Skipper additionally tests multi-mapping/repetitive-element windows. Success yields the reproducible_enriched_windows output file with statistics for significantly enriched windows found in all replicates, plus reproducible_enriched_re (repeat element) results and QC/multiqc reports.

## Related tools

- **Skipper** (End-to-end pipeline that tiles windows over annotated transcripts, builds the beta-binomial model against matched input, applies skyscraper (GINI_CUTOFF) and Flipper (THRESHOLD_MIN) filters, and calls reproducible enriched windows) — https://github.com/YeoLab/skipper
- **Snakemake 9.12.0** (Workflow engine that executes the window-testing stages and auto-generates conda environments, GFF partitions, and feature annotations)

## Examples

```
snakemake -s Skipper.py --configfile Skipper_config.yaml --profile profiles/example_slurm
```

## Evaluation signals

- reproducible_enriched_windows file exists in WORKDIR/output and contains statistics for significantly enriched windows found in all replicates
- reproducible_enriched_re (repeat element) outputs are generated, confirming multi-mapping/repetitive-element windows were tested
- QC and multiqc reports are produced, confirming the preprocessing, trimming, and STAR alignment stages completed
- On ENCODE benchmarks Skipper calls 210%-320% more transcriptomic binding sites (sometimes >1,000%) than existing methods — results falling far below comparably-run peak callers warrant investigation
- Bound repetitive elements are identified for ~99% of eCLIP experiments in the reference analysis, providing a rough completeness check

## Limitations

- Skipper requires a matched input sample to construct the beta-binomial model; CLIP datasets lacking these controls currently cannot be analyzed using Skipper
- Post hoc fine-mapping does not learn sequence motifs or binding affinity directly from CLIP data
- Users can blacklist reproducible regions of their choosing, but further work on best practices for blacklisting is warranted
- The first Skipper run is slow because conda environments are set up via snakeconda, the GFF must be parsed, and the STAR genome index generated
