# scatac-seq-peak-dropping-corruption

## Summary

Benchmark the robustness of scATAC-seq clustering tools to data sparsity by randomly dropping peaks from the count matrix at graded corruption levels (e.g., 10%-90%) and comparing ARI degradation, as demonstrated on the Forebrain dataset with SCALE, scABC, and scVI.

## When to use

Use when you need to quantify how a scATAC-seq clustering method's accuracy (ARI) degrades as sparsity increases, by simulating missingness through random peak dropping on a labeled dataset such as Forebrain (2088 cells, k=8).

## When NOT to use

- The input data already has intrinsic missingness levels you cannot control — the skill requires explicitly controlled, graded corruption levels for a fair dose-response curve.
- The dataset lacks ground-truth cell labels, since ARI against known labels is the sole evaluation metric.
- The goal is data integration or batch-effect removal rather than clustering robustness — SCALE is not specifically designed to identify and remove batch effects or other artifacts from the input data.

## Inputs

- Forebrain.h5ad dense scATAC-seq count matrix from http://zhanglab.net/SCALE_SOURCE_DATA/Forebrain.h5ad (2088 cells, k=8 clusters)
- Known Forebrain cell-type labels for ARI computation
- Corrupted count matrices generated by random peak dropping at 10%-90% removal levels

## Outputs

- ari_robustness.csv tabulating ARI as a function of corruption level for SCALE, scABC, and scVI
- Per-run SCALE outputs: model.pt, adata.h5ad (with Leiden cluster assignments), umap.pdf

## How to apply

Download the dense Forebrain.h5ad count matrix from zhanglab.net (k=8 clusters, 2088 cells) and generate random peak-dropping corruptions of the count matrix at graded levels from 10% to 90% peak removal, ensuring the 30% level is included. For each corruption level, run SCALE.py on the corrupted input with -k 8, initial learning rate 0.002 (the default), max_iter 30000 (the default), and random seed 18 (the default), saving model.pt, adata.h5ad, and umap.pdf per run. Compute the Adjusted Rand Index (ARI) between the Leiden cluster assignments stored in each adata.h5ad and the known Forebrain cell labels. Repeat the identical corruption-and-clustering protocol with baselines scABC and scVI to obtain comparative ARI values, then tabulate ARI as a function of corruption level (e.g., ari_robustness.csv). Validation requires reproducing the reported degradation: SCALE's ARI falls from 0.668 on raw data to 0.448 at 30% corruption, while scABC falls from 0.315 to 0.222 and scVI from 0.448 to 0.388, with SCALE retaining the highest ARI at each corruption level.

## Examples

```
SCALE.py -d Forebrain_corrupted30.h5ad -k 8 --lr 0.002 --max_iter 30000 --seed 18 -o out_30pct
```

## Evaluation signals

- SCALE ARI trajectory reproduces the reported degradation: 0.668 (raw) -> 0.448 at 30% corruption
- scABC ARI falls from 0.315 to 0.222 and scVI from 0.448 to 0.388 across the corruption gradient
- SCALE retains the highest ARI at every corruption level compared to scABC and scVI
- Each SCALE run produces the expected output triplet: model.pt, adata.h5ad with Leiden assignments, and umap.pdf
- ARI is computed against the same known Forebrain cell labels for all tools and corruption levels, ensuring a fair comparison

## Limitations

- SCALE is not specifically designed to identify and remove batch effects or other artifacts from the input data; explicit modeling of batch effects is deferred to future work
- Results depend on fixed hyperparameters (lr=0.002, max_iter=30000, seed=18, k=8); changing these may alter the ARI degradation curve
- The corruption model (random peak dropping) simulates missingness uniformly and may not reflect real biological or technical sparsity patterns
