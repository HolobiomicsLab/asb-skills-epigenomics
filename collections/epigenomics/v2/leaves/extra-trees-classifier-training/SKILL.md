# ExtraTrees classifier training for DNA 6mA prediction (csDMA)

## Summary

Trains the csDMA predictor by benchmarking five classifiers with 5-fold cross-validation on Motif+Kmer+Binary encoded DNA sequence features, then generating the ExtraTrees model file (csDMA.pkl) and a normalization file for downstream prediction of DNA 6mA sites.

## When to use

Use when training a DNA 6mA site predictor from labeled 41nt sequence benchmarks (e.g. cross-species, rice, M. musculus) and you must select among RandomForest, GradientBoosting, AdaBoost, ExtraTrees, and SVM classifiers via 5-fold cross-validation.

## When NOT to use

- Input is already a trained model file or a feature table — this skill is for encoding raw sequences and training, not for prediction or testing (use csDMA_indepedent_testing.py instead)
- Only a jackknife or LeaveOneOut evaluation is required — use leaveoneout.py rather than classifier selection + training
- The target species/task is outside DNA 6mA modification prediction, e.g. other epigenomic modification types not covered by the csDMA feature encoding

## Inputs

- training positive 6mA sequence dataset (FASTA-like sequence files, e.g. 41nt samples from the cross-species, rice, or M. musculus benchmarks)
- training negative sequence dataset
- matrix_motif1 / matrix_motif2 motif score matrices generated by feature_selection.py (Motif + Kmer + Binary encoding)

## Outputs

- csDMA.pkl — serialized ExtraTrees model file usable directly for prediction
- normalization.pkl — normalized (scaled) model file used to normalize input feature data
- 5-fold cross-validation performance scores (AUC, ACC, Sn, Sp, MCC) per candidate classifier

## How to apply

Encode each training sequence using the Motif, Kmer (k=2,3,4; 336 k-mer patterns), and Binary schemes implemented in feature_selection.py, producing the matrix_motif1 and matrix_motif2 score matrices. Run classifier_selection.py to train and 5-fold-cross-validate the five candidate models plus an ensemble; the article reports the ExtraTrees model achieved the best AUC of 0.878 on the training dataset and 0.893 on the independent test set, motivating its selection. Then run csDMA_training.py with the same datasets and motif matrices to output the serialized ExtraTrees model file csDMA.pkl plus a normalization file (normalization.pkl) that standardizes future input data. Validate the trained model with csDMA_indepedent_testing.py on the held-out 20% stratified test split before any comparison against baselines such as iDNA6mA-PseKNC.

## Evaluation signals

- The ExtraTrees model should reach AUC ≈ 0.878 by 5-fold cross-validation on the training dataset (paper's reported value: 0.878, vs 0.871 for the Motif+Kmer+Binary feature subset selection step).
- Independent testing should yield AUC ≈ 0.893 for the ExtraTrees model; a large gap signals an encoding or split error.
- csDMA_training.py must emit both csDMA.pkl and normalization.pkl; prediction without applying the normalization file is a misuse.
- Across all five benchmarked classifiers, ExtraTrees should rank best (or tie with the ensemble); if RandomForest/GradientBoosting/AdaBoost/SVM outperform ExtraTrees, re-check matrix_motif1/matrix_motif2 inputs.
- Training set must follow the 80/20 stratified split of the CD-HIT-EST-reduced (threshold 0.80) cross-species benchmark (2,768 positive / 2,716 negative, 41nt).

## Limitations

- csDMA was implemented in Python 2.7; the training scripts assume that environment and the provided motif matrix formats.
- Performance was relatively low on the rice and cross-species datasets compared with the M. musculus dataset; genomic and structural feature encodings were not yet incorporated.
- The baseline i6mA-Pred could not be compared directly (its method was unreachable during the study), so cross-validation comparisons are limited to reimplemented iDNA6mA-PseKNC (SVM C=0.336, gamma=0.02).
