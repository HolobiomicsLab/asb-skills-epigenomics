# dna-binding-motif-sequence-curation

## Summary

Removes poorly matching sequences from the Delila-PY cycle-2 book by applying the ri program's deterministic cutoff: any sequence with ≤0 bits of information content (computed via alist/encode/cmp/rseq) is dropped, and the retained sequences are fed back to delila to regenerate an updated book file before motif generation.

## When to use

Use when running Delila-PY's second cycle and per-sequence information content (bits) values are available, and poorly matching sequences (≤0 bits) must be removed before regenerating the book with delila.

## When NOT to use

- The pipeline is in cycle 1, where malign and malin select the highest-information alignment and no ≤0-bit cutoff is applied
- Per-sequence information content values have not yet been computed (alist/encode/cmp/rseq have not run)
- Generating the final motif in cycle 3, which uses alist, encode, cmp, rseq, dalvec, and makelogo rather than ri-based filtering

## Inputs

- Per-sequence information content values (bits) from cycle-2 alist/encode/cmp/rseq computation
- Cycle-2 book of sequences generated by delila
- Delila library files (from dbbk and catal)

## Outputs

- Filtered sequence list file containing only sequences with information content >0 bits
- Updated book file regenerated by delila from the filtered sequence list
- Counts of retained and removed sequences

## How to apply

Load the cycle-2 per-sequence information content values (in bits), produced by the alist/encode/cmp/rseq computation, into a table. Apply the ri program rule deterministically: retain a sequence if its information content is >0 bits and remove it if it is ≤0 bits, since ri is the Delila-PY mechanism for removing poorly matching sequences. Write the retained sequences to a filtered sequence list file and feed that file back to the delila program, together with the library files, to generate an updated book file. Validate by independently recounting: the number of retained plus removed sequences must equal the input table size, and no retained sequence may have information content ≤0 bits. This curation step precedes cycle 3 (alist, encode, cmp, rseq, dalvec, makelogo), so a mistake here propagates into the final DNA motif.

## Related tools

- **ri** (Applies the ≤0 information-content cutoff rule to remove poorly matching sequences)
- **delila** (Regenerates the updated book file from the filtered sequence list and library files) — https://github.com/GLBRC/delila
- **Delila-PY** (Python3 pipeline that orchestrates the ri filtering and delila feedback step) — https://github.com/GLBRC/delila
- **rseq** (Produces the per-sequence information content values used for the ≤0-bit retention decision)

## Examples

```
python delila_pipeline.py -g Rsphaeroides_GenBank.gbff -l -10 -r -10 -s Location_File_Example.txt -t "Logo Title"  # cycle 2 ri filter runs inside this pipeline
```

## Evaluation signals

- Number of retained plus number of removed sequences exactly equals the number of rows in the input information-content table
- No sequence classified as retained has information content ≤0 bits when the cutoff is independently reapplied to the table
- Every sequence classified as removed has information content ≤0 bits under independent recounting
- The updated book file is regenerated successfully by delila from the filtered sequence list without errors
- Counts match an independent (e.g., Python) application of the ≤0-bit cutoff to the input table

## Limitations

- The cutoff is fixed at ≤0 bits of information content; sequences with marginally positive information content are always retained regardless of alignment quality
- The filter depends on the accuracy of the cycle-2 information content computation (alist/encode/cmp/rseq); errors there propagate into the retained set
- Filtering changes the sequence set, so the regenerated book differs from the original and downstream motif (cycle 3) results reflect only retained sequences
