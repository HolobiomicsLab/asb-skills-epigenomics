# per-tissue-cross-validation-evaluation

## Summary

A benchmarking skill for evaluating TIVAN-indel against CADD/FATHMM-indel (SVM) and DanQ/DeepSEA (Boosted LR) baselines using 5-fold cross-validation within each of 44 GTEx tissues, reporting per-tissue and median AUROC/AUPRC for non-coding regulatory small indel (nc-sindel) prediction.

## When to use

Use when labeled nc-sindels (cis-eQTL positives vs negatives) must be classified per GTEx tissue and model comparison requires within-tissue AUROC/AUPRC medians across 44 tissues rather than a pooled single-split evaluation.

## When NOT to use

- Input is a raw variant list without labels or tissue assignment — the skill requires cis-eQTL-labeled positive/negative nc-sindels per GTEx tissue
- Evaluation goal is cross-tissue prediction (training on one tissue, testing on another) rather than within-tissue 5-fold CV
- Variant type is SNVs or large structural variants — the framework targets non-coding small indels (sindels) with CADD-indel annotations

## Inputs

- Positive nc-sindel list per tissue (train/snp.pos.txt: chr, start, end, refallele, altallele) from cis-eQTL analyses
- Negative nc-sindel list per tissue (train/snp.neg.txt)
- CADD.indel.rda — R rda file with CADD annotations for all indels in 1000 Genomes Project
- Reference/alternative genomic FASTA sequences generated by prepare.R (BSgenome.Hsapiens.UCSC.hg19)
- seq_features.h5 — 919 DanQ-predicted multi-omics features
- GTEx tissue labels across 44 tissues (e.g., Adipose_Subcutaneous, Brain_Cortex)

## Outputs

- Per-tissue AUROC and AUPRC for TIVAN-indel, CADD/FATHMM-indel (SVM), and DanQ/DeepSEA (Boosted LR)
- Median AUROC across 44 tissues (expected: 0.983 / 0.784 / 0.753)
- Median AUPRC across 44 tissues (expected: 0.986 / 0.840 / 0.816)
- Trained model files, e.g. res/model.

## How to apply

First build the feature matrix per tissue: run prepare.R with (CADD.indel.rda, snp.pos.txt, snp.neg.txt, 'train') to extract 45 CADD annotations plus reference/alternative sequences, then run 'python prepare.py --path ../train' so the pretrained DanQ model emits 919 multi-omics features into seq_features.h5. Train TIVAN-indel with 'python train.py --path ../train --output ../res/model.' on the combined 45 CADD + 919 sequence-derived features. Train the two baselines on the 45 CADD annotations alone: a support vector machine (scikit-learn 0.24.2) and a boosted logistic regression (xgboost 1.5.1). For each of the 44 GTEx tissues, run stratified 5-fold cross-validation with all three models, computing AUROC and AUPRC per fold, then average per tissue and take the median across tissues. Correct application reproduces the paper's medians: TIVAN-indel AUROC 0.983 vs SVM 0.784 vs Boosted LR 0.753, and AUPRC 0.986 vs 0.840 vs 0.816 (Results 3.2, Figure 3).

## Evaluation signals

- Median AUROC across the 44 GTEx tissues equals 0.983 (TIVAN-indel), 0.784 (SVM baseline), 0.753 (Boosted LR baseline)
- Median AUPRC across the 44 GTEx tissues equals 0.986 (TIVAN-indel), 0.840 (SVM baseline), 0.816 (Boosted LR baseline), matching Results 3.2 and Figure 3
- TIVAN-indel (45 CADD + 919 multi-omics features) strictly outperforms both baselines (CADD annotations alone) in nearly all per-tissue AUROC/AUPRC comparisons
- The 5-fold CV is stratified within each tissue independently; no cross-tissue leakage of samples between train and test folds
- Feature dimensions check: annot.csv carries 45 CADD annotation columns and seq_features.h5 carries exactly 919 multi-omics feature columns per indel

## Limitations

- Performance is anchored to cis-eQTL-derived labels in GTEx; tissues with few labeled sindels may give noisy per-tissue AUROC/AUPRC estimates
- Baselines use only the 45 generic CADD annotations, so the comparison conflates feature set size (45 vs 964 features) with model architecture
- DanQ multi-omics features depend on the pretrained checkpoint trained on DeepSEA data; training a custom DanQ model requires external data from http://deepsea.princeton.edu/help/
