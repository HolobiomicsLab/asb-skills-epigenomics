# similarity-matrix-heatmap-visualization

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Compute pairwise Jaccard similarity indices between the top-10/50/100 transcriptional regulator (TR) lists produced by six methods (BIT, BART, ChIP-Atlas, i-cisTarget, HOMER, WhichTF) on the same epigenomic query region sets, and render the resulting method-by-method matrices as heatmaps mirroring Supplementary Fig. 9.

## When to use

Use when you have ranked TR (or other entity) tables from multiple methods applied to identical query region sets and need to quantify and visualize cross-method agreement of top-k lists via Jaccard indices and heatmaps.

## When NOT to use

- You need agreement between full ranked lists rather than top-k set overlaps — the paper benchmarks full ranking agreement with mean reciprocal rank (MRR), not Jaccard indices
- Query region sets differ across methods (e.g., different peak inputs), since the Jaccard comparison assumes all methods were applied to the same epigenomic query region sets

## Inputs

- Ranked TR tables (one per method: BIT, BART2, ChIP-Atlas, i-cisTarget, HOMER, WhichTF) for TR perturbation-derived DARs
- Ranked TR tables for cancer-type-specific accessible region sets (TCGA-derived)
- Top-k cutoff values (k = 10, 50, 100)

## Outputs

- Method-by-method Jaccard similarity matrices for each k and region-set type
- CSV table of pairwise Jaccard indices
- Heatmap of the similarity matrices mirroring Supplementary Fig. 9

## How to apply

Load the ranked TR tables generated by each of the six methods (BIT, BART2, ChIP-Atlas, i-cisTarget, HOMER, WhichTF) for the TR perturbation-derived DARs and the cancer-type-specific accessible region sets. For each query region set and each top-k cutoff (k = 10, 50, 100), extract the set of top-k ranked TR names per method, then compute all pairwise Jaccard indices as |intersection| / |union| of the top-k TR sets. Assemble the indices into method-by-method similarity matrices for each k and region-set type, write them to a CSV table, and render each matrix as a heatmap. Validation relies on the expectation that the reproduced pairwise Jaccard values should be generally low across methods, consistent with the paper's report on Supplementary Fig. 9.

```
Rscript -e 'jaccard <- function(a,b) length(intersect(a,b))/length(union(a,b)); j <- jaccard(top10$BIT, top10$BART2)'
```

## Evaluation signals

- Reproduced pairwise Jaccard values should be generally low across methods, consistent with the paper's Supplementary Fig. 9
- Similarity matrices must be symmetric with a diagonal of 1 (Jaccard of a set with itself)
- All Jaccard values fall in [0, 1] for every pairwise comparison at each k in {10, 50, 100}
- One matrix and heatmap produced per combination of k and region-set type (TR perturbation-derived DARs and cancer-type-specific accessible regions)
- Jaccard values equal |intersection| / |union| of the exact top-k TR name sets — spot-check a few pairs by recomputing from the ranked tables

## Limitations

- Comparisons reference Supplementary Figures 9, 10a, 10b, and 10c, which are not present in the provided text — exact numeric reproduction may require the original supplementary files
- Low Jaccard similarity is itself the reported finding; it does not by itself indicate which method is more correct — rank-based metrics such as MRR are used for accuracy benchmarking
- Jaccard on top-k sets is sensitive to the choice of cutoff (k = 10, 50, 100); conclusions may differ across cutoffs
