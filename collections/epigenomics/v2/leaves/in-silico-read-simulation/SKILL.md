# in-silico-read-simulation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Generate simulated methylome sequencing reads with the SHERMAN script under the TAPS protocol (C->T conversion 20% at CpG, 0.5% at CpH, 0.1% sequencing error) so that aligner mapping efficiency and accuracy can be benchmarked against known ground truth.

## When to use

Use when benchmarking methylation read aligners (e.g., Msuite vs Bismark vs BWA-meth) on ground-truth data, or when stratifying mapping performance by region composition such as CT/GA-rich bins.

## When NOT to use

- Analyzing real sequencing data or biological conclusions — simulation is only valid for in-silico benchmarking against known truth coordinates
- Data generated by BS-seq protocol where 4-letter mode is not applicable (README: 4-letter mode ONLY supports TAPS/5hmC-CATCH data)
- Reads longer or shorter than the tested 36-/100-bp paired-/single-end configurations without re-validating the benchmark parameters

## Inputs

- Human reference genome FASTA (e.g., hg19/hg38, GRCh38) as multi-fasta or per-chromosome directory
- RefSeq annotation (files for mm9/mm10/hg19/hg38 included in the Msuite package)
- Benchmark-generation scripts from the Msuite GitHub deposit (SHERMAN script, mined CT/GA-rich regions)

## Outputs

- Four in silico datasets of paired-/single-end 36-/100-bp TAPS-protocol FASTQ reads (1 million read pairs each)
- CT/GA-stratified simulated read sets (500-bp bins with CT/GA proportion >=70% and >=80%)
- Benchmark metrics per tool/mode: mapping efficiency (%), mapping accuracy (%), running time, peak memory (e.g., table2_benchmark.tsv / table2_ct_ga_mapping_efficiency.csv)

## How to apply

Simulate 1,000,000 paired-end 36-bp or 100-bp read pairs with the SHERMAN script using the paper's key parameters: C->T conversion rate of 20% for CpG sites, 0.5% in CpH sites, and 0.1% sequencing error rate. Restrict sampling to 500-bp human-genome bins stratified by CT/GA proportion (>=70% and >=80% strata) when testing the CT/GA-rich-region advantage, using the mined CT/GA-region scripts from the Msuite GitHub deposit. Before aligning the simulated reads, build genome indices with Msuite's build.index.sh utility (e.g., hg19/hg38 FASTA plus RefSeq annotation), which automatically incorporates the Lambda genome. Align the simulated FASTQs with Msuite in 3-letter mode (-3 -m TAPS) and 4-letter mode (-4 -m TAPS) and with Bismark v0.22.3 and BWA-meth v0.2.2 under matched settings; measure mapping efficiency, accuracy, time (/usr/bin/time), and peak memory.

## Related tools

- **SHERMAN script** (Generates the in-silico TAPS-protocol read sets with specified conversion and error rates)
- **Msuite** (Aligns simulated reads in 3-letter (-3) and 4-letter (-4) TAPS mode after building indices with build.index.sh) — https://github.com/hellosunking/Msuite/
- **Bismark** (3-letter (bowtie2-based) baseline aligner run on the same simulated read sets)
- **BWA-meth** (3-letter baseline aligner for the benchmark comparison)
- **bowtie2** (Underlying aligner used by both Msuite and Bismark; must be in PATH) — https://github.com/BenLangmead/bowtie2
- **samtools** (Converts SAM alignment output to BAM format during pipeline evaluation)

## Examples

```
build.index/build.index.sh hg19.fa refseq_hg19.txt.gz hg19
```

## Evaluation signals

- Simulated datasets contain 1,000,000 read pairs per configuration (36-bp and 100-bp paired-end) at the specified conversion/error rates
- CT/GA-stratified benchmark reproduces the reported values: Msuite 4-letter ME 79.67% and accuracy 99.78% vs 3-letter 67.14%/99.03% on CT/GA >=70% bins
- Table 2 mapping efficiency reproduced within rounding tolerance (Msuite 3-letter 96.19%, 4-letter 95.75%, Bismark 95.79%, BWA-meth 95.58% on 100-bp reads)
- Multi-mapping reads with equal best scores are discarded; only unique best hits count toward mapping efficiency
- Msuite shows faster speed and lower peak memory than Bismark and BWA-meth despite its additional trimming step

## Limitations

- In silico conversion rates (20% CpG / 0.5% CpH) are idealized; the real TAPS dataset had imperfect chemical treatment
- Benchmark conclusions are specific to the simulated read lengths and CT/GA-region strata tested
- Building the genome index with build.index.sh automatically incorporates the Lambda genome, so indices differ slightly from a plain reference
