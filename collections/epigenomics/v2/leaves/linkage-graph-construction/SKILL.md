# linkage-graph-construction

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Reconstructs SpecHap's linkage graph: heterozygous variant loci become nodes of an undirected graph whose edge weights are truncated log-likelihood ratios, weight = max(log(p(H1)/p(H2)), 0), computed from fragment Phred probabilities. This graph is the representation on which SpecHap's Fiedler-Vector-guided spectral partitioning operates.

## When to use

Use when building the weighted undirected linkage graph that SpecHap needs for spectral haplotype phasing, starting from extractHAIRS fragment files (10X/Hi-C, PacBio SMRT, ONT, paired-end NGS).

## When NOT to use

- The linkage graph already exists — rebuilding edges is redundant before running SpecHap on the fragment file
- Ploidy greater than 2: the article states the current graph bisection model might not fit when the ploidy increases
- Haplotype-resolved structural variation or genome rearrangements: SpecHap supports only SNPs, short insertions and deletions, so no rearrangement-aware linkage graph can be built

## Inputs

- Position-sorted fragment file produced by extractHAIRS (ExtractHair, modified from HapCUT2), ordered consistently with the VCF
- VCF of heterozygous variant calls defining the fragment file ordering

## Outputs

- linkage_graph.tsv — tab-delimited weighted undirected linkage graph (node = heterozygous variant locus, edge = truncated log-likelihood-ratio weight)

## How to apply

Parse the position-sorted fragment file generated by extractHAIRS (the ExtractHair utility modified from HapCUT2) only after confirming it was sorted consistently with the VCF order — sort -n -k6 for 10X/Hi-C or new-format fragments, sort -n -k3 for paired-end NGS, PacBio SMRT or Oxford Nanopore default format. Define the heterozygous variant loci covered by fragments as the nodes of an undirected graph. For every pair of loci co-observed on the same fragment, compute the log-likelihood ratio of the two conflicting haplotype-pair assignments (H1 vs H2) from the fragment's base Phred probabilities, truncate it, and assign the maximum truncated value — max(log(p(H1)/p(H2)), 0) — as the edge weight between the two loci. Emit the weighted undirected graph (node = variant locus, edge = truncated LLR weight) as a tab-delimited table, linkage_graph.tsv. The rationale is that this truncated-LLR graph is exactly the matrix representation on which SpecHap's spectral analysis (Fiedler Vector min-cut heuristic) runs, so faithful node/edge reconstruction directly determines downstream haplotype partitioning.

## Related tools

- **SpecHap** (Consumer of the linkage graph: its Fiedler-Vector-guided min-cut partitioning (spectral graph analysis) operates on this truncated-LLR weighted undirected graph to partition alleles into haplotypes) — https://github.com/deepomicslab/SpecHap
- **HapCUT2** (Source of the ExtractHair/extractHAIRS fragment-extraction utility (bundled as a modified SpecHap submodule) that generates the fragment file from which the graph is reconstructed) — https://github.com/vibansal/HapCUT2
- **htslib** (Required dependency for building the bundled ExtractHair fragment-processing utility used to produce the graph's fragment input) — https://github.com/samtools/htslib

## Examples

```
sort -n -k6 fragments.tsv > fragments.sorted.tsv  # 10X/Hi-C/new-format; use sort -n -k3 for paired-end NGS, PacBio SMRT, ONT
```

## Evaluation signals

- linkage_graph.tsv exists and is tab-delimited
- Every edge weight is a finite numeric log-likelihood-ratio value (non-negative after truncation via max(log(p(H1)/p(H2)), 0))
- The node set matches the heterozygous loci covered by fragments in the input fragment file
- Every edge corresponds to a pair of loci co-observed on at least one fragment
- Fragment file order was confirmed consistent with the VCF order using the specified sort key (-k6 for 10X/Hi-C/new-format; -k3 for paired-end NGS, PacBio SMRT, ONT) before parsing

## Limitations

- Current graph bisection model does not fit increased ploidy; high-ploidy generalization is not implemented
- The linkage graph supports only SNPs, short insertions and deletions; a refined graph incorporating genome rearrangements is not yet available
- No software version stated for SpecHap, and no comprehensive analysis of technology-specific error influence (Hi-C, 10X linked-reads) on phasing quality has been conducted
