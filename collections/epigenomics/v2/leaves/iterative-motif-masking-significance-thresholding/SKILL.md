# Iterative motif masking with significance thresholding

## Summary

De novo discovery of m5C methylase specificity motifs from RIMS-seq C-to-T foreground sequences using MosDi, with iterative masking of top-scoring motifs until no motif with P < 1e-100 remains, yielding methylase_specificities.txt.

## When to use

Use when RIMS-seq Read1/Read2 mpileup files contain C-to-T (and G-to-A) positions and you must de novo identify enriched methylated motifs without a known motif, validating against an expected motif such as CCWGG.

## When NOT to use

- When a trusted reference genome/motif is already known and no de novo discovery is needed
- When methylation signal is too sparse for combined-read detection — RIMS-seq signals require enough read coverage to compensate for the scarcity of sites
- When the library was prepared by tagmentation rather than adapter ligation, since RIMS-seq does not work for such protocols

## Inputs

- Read1 and Read2 mpileup files produced by split_mapped_reads.pl from the BWA-mem .bam
- Foreground C-to-T / G-to-A position sequences with 14 bp flanks (min base quality 35) and matched background sequences generated by get_motif_all.pl

## Outputs

- methylase_specificities.txt listing the discovered methylated motifs (e.g. CCWGG for E. coli K12 MG1655)

## How to apply

After get_motif_all.pl extracts foreground C-to-T (and G-to-A) positions with 14 bp flanks (7 bp each side) at minimum base quality 35 plus matched background positions, run mosdi-discovery with the parameter string '-v discovery -q x -i -T 1e-100 -M 8,1,0,4 8 occ-count', where -T 1e-100 sets the significance cutoff and '8,1,0,4' specifies the motif model parameters (motif length 8). Take the top-scoring motif, mask it in the input sequences, and re-run mosdi-discovery iteratively until no motif with P < 1e-100 remains; the collected motifs constitute the methylase specificities written to methylase_specificities.txt. Downsampling the paired-end reads to 1-5 million is recommended first to avoid lengthy processing time during motif discovery.

## Related tools

- **MosDi** (motif discovery engine (mosdi-discovery) run on foreground/background C-to-T sequences with '-T 1e-100 -M 8,1,0,4 8 occ-count') — https://bitbucket.org/tobiasmarschall/mosdi/src/master/
- **get_motif_all.pl** (extracts foreground and background positions from the two mpileup files and identifies the methylase specificity using MosDi; orchestrates the iterative masking) — https://github.com/Ettwiller/RIMS-seq/
- **split_mapped_reads.pl** (splits the BWA bam into Read1 and Read2 mpileup files (via samtools mpileup) that feed the motif discovery step) — https://github.com/Ettwiller/RIMS-seq/

## Examples

```
mosdi-discovery -v discovery -q x -i -T 1e-100 -M 8,1,0,4 8 occ-count
```

## Evaluation signals

- methylase_specificities.txt exists and is non-empty at the end of the run
- On the E. coli K12 MG1655 test data (ecoli_rims_3h_5M.1/.2.fastq.gz), the recovered methylated motif matches the expected CCWGG
- The iterative loop terminates because no further motif reaches P < 1e-100 (the -T significance threshold)
- Every reported motif is enriched in foreground C-to-T flanks relative to matched background positions
- Input reads were downsampled to 1-5 million pairs so motif discovery completes in reasonable time

## Limitations

- Single nucleotide polymorphisms in microbial communities may confound C-to-T deamination detection, increasing background noise for motif detection
- Uneven species representation in microbiomes can cause motifs to be identified only in the most abundant species, and assigning motifs to the correct species is challenging for closely related co-existing species
- Low-coverage or rare motif sites may not yield a detectable signal because RIMS-seq requires combined signal over many reads; partially methylated sites need further evaluation
