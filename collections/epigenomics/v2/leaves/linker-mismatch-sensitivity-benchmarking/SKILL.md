# linker-mismatch-sensitivity-benchmarking

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Benchmarks the sensitivity of ChIA-PET bridge-linker trimming by re-running ChIA-PET2 trimLinker at increasing linker-search mismatch allowances (-e) and comparing rescued PET counts and valid PET ratios reported in output.trim.stat.

## When to use

Use when processing bridge-linker ChIA-PET FASTQ reads and you must quantify how much PET rescue a fuzzy linker search (e.g., -e 1 vs -e 0) yields before fixing the trimming stringency.

## When NOT to use

- Data were generated by the half-linker ChIA-PET protocol; bridge-linker mode and the linkerA/linkerB settings of ACGCGATATCTTATCTGACT do not apply.
- Reads are already linker-trimmed and the task is a downstream ChIA-PET2 step (read alignment, PET filtering, PCR duplicate removal, peak or loop calling).
- The goal is tuning chromatin loop-calling significance thresholds to balance sensitivity and specificity of loop calls, not quantifying linker-trimming PET rescue.

## Inputs

- Paired-end ChIA-PET FASTQ(.gz) raw reads (GM12878 CTCF, NCBI GEO GSE72816 / GSM970213)
- Bridge-linker sequence ACGCGATATCTTATCTGACT split into 15-nt linkerA (ACGCGATATCTTATC) and linkerB (AGTCAGATAAGATAT)
- Two trimLinker parameter sets identical except for mismatch allowance (-e 0 vs -e 1; with -m 1, -k 0, -l 15)

## Outputs

- Trimmed paired-end FASTQ(.gz) files from each trimLinker run
- output.trim.stat summary per run reporting rescued PET counts and valid PET ratio
- Comparison metrics: rescued PETs (expected >16 million) and valid-PET-ratio improvement (expected ~12.85%) at -e 1 relative to -e 0

## How to apply

Retrieve the GM12878 CTCF ChIA-PET paired-end FASTQ (NCBI GEO GSE72816 / GSM970213) and run ChIA-PET2 trimLinker in bridge-linker mode (-m 1) with the first 15 bases of each 5' end of the bridge linker ACGCGATATCTTATCTGACT supplied as linkerA=ACGCGATATCTTATC and linkerB=AGTCAGATAAGATAT, using -k 0 and minimum trimmed read length 15 (-l 15). Run the identical command twice, once allowing zero mismatches (-e 0) and once allowing one mismatch (-e 1), so the mismatch allowance is the only varying parameter. Parse each run's output.trim.stat summary to extract the number of rescued PETs and the valid PET ratio. Benchmark the -e 1 run against the reported result of >16 million rescued PETs and a 12.85% improvement in the valid PET ratio over the strict -e 0 setting. If the delta deviates strongly, verify that -m, -k, -l, linkerA and linkerB are unchanged and that the input is raw, not pre-trimmed FASTQ.

## Related tools

- **ChIA-PET2** (Supplies the trimLinker subcommand used to trim bridge-linker sequences from paired-end FASTQ at a configurable mismatch allowance (-e) and to emit the output.trim.stat QC summary used to compute rescued PETs and the valid PET ratio) — https://github.com/GuipengLi/ChIA-PET2

## Examples

```
ChIA-PET2 trimLinker -m 1 --linkerA ACGCGATATCTTATC --linkerB AGTCAGATAAGATAT -e 1 -k 0 -l 15 -i read1.fq.gz -I read2.fq.gz
```

## Evaluation signals

- The -e 1 output.trim.stat reports >16 million rescued PETs versus the -e 0 run on the GM12878 CTCF dataset (GSE72816/GSM970213).
- The valid PET ratio at -e 1 exceeds the -e 0 value by approximately 12.85%.
- The two runs differ only in -e (0 vs 1); -m 1, -k 0, -l 15, linkerA and linkerB are identical, so the PET-count delta is attributable solely to mismatch tolerance.
- Trimmed reads respect the minimum trimmed length of 15 (-l 15) and linker matching uses the first 15 bases of each 5' end of ACGCGATATCTTATCTGACT.
- Rescued PET delta is non-negative and trim.stat PET totals reconcile with the input paired-read counts.

## Limitations

- The benchmark figures (>16 million rescued PETs, 12.85% valid-PET-ratio improvement) are specific to the GM12878 CTCF ChIA-PET dataset; other datasets or linker sequences will yield different rescue levels.
- Tolerating linker mismatches trades sensitivity against specificity: fuzzy matching can mis-identify linkers, and ChIA-PET2 users must choose thresholds to balance sensitivity and specificity.
- No ChIA-PET2 software version is stated in the article or README, so exact reproduction may depend on which release or commit is used.
