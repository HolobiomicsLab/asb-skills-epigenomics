# differential-expression-threshold-estimation

## Summary

A bootRanges-based spline-fitting procedure that derives data-driven significance thresholds for differential analysis — e.g. SNPs with -log10(P-value) > 8 and genes with |logFC| > 2 in the Alasoo 2018 macrophage dataset — by locating where the observed penalized-spline fit over logFC separates from the block-bootstrap null envelope.

## When to use

Use when overlap counts between differential expression genes and differential accessibility peaks (or SNP/gene statistics) are available and an objective, bootstrap-justified logFC or P-value cutoff is needed instead of an arbitrary threshold.

## When NOT to use

- The analysis goal is a simple enrichment z score at a fixed, pre-specified cutoff rather than optimizing the threshold itself (use the standard bootRanges var.R overlap-rate/z-score workflow instead).
- The input consists of caQTL–SNP overlap rates in human liver tissue (the liver script uses splines for a conditional density plot, not DEG logFC threshold optimization).
- Null sets were generated by conventional shuffling or permutation, which may produce overly narrow test statistic null distributions and over-estimate significance.

## Inputs

- Observed overlap count table of differential expression genes (with logFC) and differential accessibility peaks for the Alasoo 2018 macrophage dataset (produced via bootRanges, e.g. macrophage.R)
- Bootstrapped null overlap count tables from bootRanges block bootstrap (segBootranges.R)
- SNP -log10(P) statistics and gene log fold change statistics from differential analysis

## Outputs

- Fitted penalized-spline GLM over logFC for observed and null sets (conditional density plot from fit_splines.R)
- Optimized data-driven thresholds: SNPs -log10(P) > 8 and genes |logFC| > 2
- fitted_thresholds.csv containing the recovered thresholds

## How to apply

Load the observed overlap count table linking differential expression genes (logFC) and differential accessibility peaks (from the Alasoo 2018 macrophage dataset) generated with the bootRanges workflow. Fit a generalized linear model with a penalized-spline (P-spline) smooth term on logFC to the observed overlap counts (fit_splines.R, visualized as a conditional density plot), then fit the same penalized-spline GLMs to each block-bootstrapped null set from bootRanges (segBootranges.R) to build the null distribution of the spline fit over logFC. Identify the logFC (and corresponding SNP -log10(P)) values where the observed spline diverges from the null spline envelope, i.e. where the z score reflects strong separation of the observed statistic from the bootstrap distribution; for this dataset this recovers SNPs -log10(P) > 8 and genes |logFC| > 2. Write the recovered cutoffs to fitted_thresholds.csv. The rationale is that block bootstrap preserves local genomic correlation structure, giving more reliable null distributions than shuffling or permutation, which can yield overly narrow null distributions and over-estimated significance.

## Evaluation signals

- The recovered thresholds equal SNPs -log10(P) > 8 and genes |logFC| > 2 for the Alasoo 2018 macrophage dataset.
- The observed spline shows strong separation from the null spline envelope at the selected logFC values, i.e. z score reflects strong separation of the observed statistic from the bootstrap distribution.
- Null spline distributions were fit to every bootRanges null set, not just the observed data.
- fitted_thresholds.csv is produced and contains the recovered threshold values.
- Block bootstrap (not shuffling/permutation) was used, preserving local genomic correlation structure in the null sets.

## Limitations

- Shuffling or permutation schemes may result in overly narrow test statistic null distributions and over-estimation of statistical significance; block bootstrap should be used instead.
- Thresholds (e.g. |logFC| > 2) are dataset-specific and must be re-derived from the observed-vs-null spline divergence for each new dataset.
- The workflow is specific to paired differential accessibility/differential expression range data (e.g. macrophage.R); other scripts (liver, multiomicsCor.R) address different questions.
