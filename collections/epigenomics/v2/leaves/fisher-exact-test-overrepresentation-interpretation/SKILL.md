# fisher-exact-test-overrepresentation-interpretation

## Summary

Applies the Fisher's exact test with Holm–Bonferroni P-value adjustment to filter over-represented IUPAC motifs candidate-generated by DiNAMO's lattice, distinguishing statistically significant motifs from MI-selected ones.

## When to use

Use when a candidate motif set (e.g., DiNAMO IUPAC lattice nodes) must be statistically filtered for over-representation in a positive (signal.fa) versus negative (control.fa) dataset with multiple-testing correction.

## When NOT to use

- When ranking or comparing motifs irrespective of occurrence count — use mutual information instead, which 'captures the dependency between a motif and a dataset independently from its number of occurrences'
- When no matched negative/control dataset exists, since the Fisher's exact test requires counts in both signal and control files

## Inputs

- MI-simplified IUPAC motif lattice nodes from DiNAMO (positive signal.fa vs negative control.fa counts)
- Contingency tables of motif occurrence counts in the positive and negative FASTA files
- Optional Fisher's exact test P-value threshold '-t' (default 0.05)

## Outputs

- Fisher's exact test P-values for each candidate motif
- Holm–Bonferroni-adjusted P-values
- Filtered set of statistically over-represented IUPAC motifs, output in MEME format (e.g., NNRGGT on the SSE dataset with adjusted P-value < 10−324)

## How to apply

After DiNAMO counts L-mers, builds the IUPAC motif lattice and simplifies it by mutual information (MI), compute a 2x2 contingency table per surviving lattice vertex containing counts for the positive and negative files. For each MI-selected motif, compute the Fisher's exact test P-value, then apply the Holm–Bonferroni method to adjust P-values and counteract multiple comparisons. Interpret MI and Fisher P-value as complementary: MI captures the dependency between a motif and a dataset independently from its number of occurrences, while the Fisher's exact test accounts for occurrence counts. Optionally set a custom significance threshold with the DiNAMO '-t' parameter (default 0.05). Only motifs passing the adjusted threshold are reported as over-represented, in MEME format.

## Related tools

- **DiNAMO** (Computes Fisher's exact test P-values for lattice-selected IUPAC motifs and applies Holm–Bonferroni adjustment; threshold customizable via '-t' (default 0.05)) — https://github.com/bonsai-team/DiNAMO

## Examples

```
dinamo -pf signal.fa -nf control.fa -l 6 -t 0.05
```

## Evaluation signals

- Adjusted P-values of reported motifs are significant after Holm–Bonferroni correction (e.g., NNRGGT on the monocyte SSE dataset with adjusted P-value < 10−324)
- Each filtered motif has a fully populated contingency table with counts from both signal.fa and control.fa
- Motifs failing the adjusted Fisher's exact test threshold (default 0.05) are excluded from the MEME-format output
- Reported motifs were previously retained by MI-based lattice simplification, confirming MI and Fisher filtering are applied in the intended order

## Limitations

- Fisher's exact test P-value depends on occurrence count, unlike MI — high-count weak motifs may pass while low-count specific motifs may not, hence the two-stage MI-then-Fisher design
- Multiple comparisons inflate false positives if Holm–Bonferroni adjustment is omitted
- Filter quality depends on a well-matched negative (control) dataset; on the SSE task the control was assembled from non-error regions matched to the 3272 monocyte error coordinates
