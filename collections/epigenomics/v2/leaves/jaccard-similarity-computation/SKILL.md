# jaccard-similarity-computation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Computes all pairwise Jaccard indices (|intersection| / |union|) between top-k (k=10, 50, 100) transcriptional regulator (TR) ranked lists produced by six TR identification methods (BIT, BART2, ChIP-Atlas, i-cisTarget, HOMER, WhichTF), assembling method-by-method similarity heatmaps to quantify cross-method agreement.

## When to use

Use when you have ranked TR output tables from multiple TR identification methods applied to the same epigenomic query region sets and need to quantify overlap of their top-ranked predictions.

## When NOT to use

- You want to measure prediction accuracy against known perturbed TRs rather than cross-method list agreement — use mean reciprocal rank (MRR) benchmarking instead, as the paper did for bulk and single-cell perturbation data
- You have raw query region sets that have not yet been run through each TR identification method to produce ranked TR lists
- You need to compare overlapping genomic regions themselves rather than the ranked TR names they produce

## Inputs

- Ranked TR output tables (one ranked list of TR names per method: BIT, BART2, ChIP-Atlas, i-cisTarget, HOMER, WhichTF) for TR perturbation-derived DAR query region sets
- Ranked TR output tables for cancer-type-specific accessible region sets (TCGA-derived)
- Top-k cutoff values (k = 10, 50, 100)

## Outputs

- Method-by-method Jaccard similarity matrices for each k and region-set type (CSV table)
- Heatmaps of the similarity matrices mirroring Supplementary Fig. 9

## How to apply

Load the ranked TR tables generated by each method (BIT, BART2, ChIP-Atlas, i-cisTarget, HOMER, WhichTF) for the TR perturbation-derived DARs and the cancer-type-specific accessible region sets. For each query region set and each top-k cutoff (k = 10, 50, 100), extract the set of top-k ranked TR names per method. Compute all pairwise Jaccard indices as |intersection| / |union| of the top-k TR sets, using R. Assemble the indices into method-by-method similarity matrices for each k and region-set type, write them to a CSV table, and render as heatmaps mirroring Supplementary Fig. 9. Note this skill measures list-overlap agreement between methods; it is complementary to the paper's accuracy benchmark, which instead used mean reciprocal rank (MRR) against known perturbed TRs.

## Examples

```
Rscript -e 'jac <- function(x,y) length(intersect(x,y))/length(union(x,y)); J <- jac(top10$BIT, top10$BART2)'
```

## Evaluation signals

- Jaccard values for every pairwise method comparison fall within [0, 1], and each similarity matrix is symmetric with diagonal entries equal to 1
- Off-diagonal Jaccard similarities are generally low across methods, consistent with the paper's report that 'Jaccard similarity among these approaches is generally low (Supplementary Fig. 9)'
- A separate similarity matrix is produced for each top-k cutoff (k = 10, 50, 100) and each region-set type (perturbation-derived DARs and cancer-type-specific accessible regions)
- Each top-k set contains exactly k TR names (provided the ranked table has at least k entries), so intersections cannot exceed k and Jaccard cannot exceed k/(2k - |intersection|) bounds
- The Jaccard of a set with itself equals 1 and with the empty set equals 0 as a sanity check of the intersection/union implementation

## Limitations

- Jaccard similarity captures only set overlap of top-k TR names; it does not consider ranking order or score magnitude, so two methods can agree on TR identity but disagree on rank (the paper used MRR for rank-aware accuracy benchmarking)
- Comparisons reference Supplementary Figures 9, 10a, 10b, and 10c, which are not present in the provided text — a reproducibility gap for validating the reproduced heatmaps directly
- Because BIT's ranking is one of the compared methods, apparent agreement or disagreement with BIT reflects BIT's Bayesian ChIP-seq-library-based approach versus motif-based (HOMER, WhichTF, i-cisTarget) and ChIP-seq-based (BART, ChIP-Atlas) approaches, which the paper notes rely on low-specificity binding motifs or linear chromosome distance
