# logistic-probability-aggregation-of-feature-similarities

## Summary

Aggregates epigenomic signal similarities and sequence grammar similarities between query regions and candidate target regions into logistic regression probability scores in AdaLiftOver, then filters scored candidates with gr_candidate_filter() to retain the best_k regions per query above a score threshold.

## When to use

Use when candidate target regions have already been generated by adaptive liftOver and both epigenomic signal similarities (from matched orthologous ENCODE ChIP-seq/DNase-seq datasets) and sequence grammar similarities (motif scanning with jaspar_pfm_list) are available to be scored and filtered.

## When NOT to use

- The task is a plain cross-species interval mapping without functional prioritization — direct UCSC liftOver alone suffices and the scoring/filtering layer is unnecessary
- No matched orthologous functional genomic datasets are available for the species pair and no parameters can be trained via training_module(), so similarities cannot be computed
- Input is a list of orthologous pairs already validated; scoring candidates is redundant

## Inputs

- Query regions and liftOver-generated candidate target regions (GenomicRanges gr_list)
- Matched orthologous epigenome repertoires (GRangesList, e.g., epigenome_mm10 and epigenome_hg38 ENCODE datasets)
- jaspar_pfm_list (position frequency matrices for motif scanning)
- Genome identifiers for BSgenome objects (e.g., 'mm10', 'hg38', 'rn6')
- Trained or averaged logistic regression parameters from training_module()

## Outputs

- Scored candidate target regions per query region (gr_list with logistic probability scores)
- Filtered gr_list (gr_candidate_filter output, at most best_k candidates per query with scores above threshold)
- Training results (logistic regression parameters and suggested optimal score threshold) when training_module() is used

## How to apply

After adaptive_liftover() generates candidate target regions per query region, compute epigenomic signal similarities with compute_similarity_epigenome() using matched orthologous functional genomic datasets (e.g., 67 matched human-mouse TF/DNA methylation ChIP-seq and DNase-seq ENCODE datasets), and compute sequence grammar similarities with compute_similarity_grammar() by motif scanning via motifmatchr against the jaspar_pfm_list. Aggregate these two similarity features with logistic regression parameters into probability scores for each candidate target region. When the target species is not mouse, estimate the logistic regression parameters with training_module() from a pair of matched epigenome datasets (e.g., rat epigenome peaks labeled as positives if candidates overlap human orthologous peaks), optionally averaging parameters across tissues. Finally, filter the scored candidates with gr_candidate_filter(), supplying best_k (maximum retained candidates per query, e.g., best_k = 1L) and a score threshold (e.g., threshold = 0.5, ideally the optimal threshold suggested by the training module).

## Examples

```
gr_list <- compute_similarity_epigenome(gr, gr_list, epigenome_mm10, epigenome_hg38); gr_list <- compute_similarity_grammar(gr, gr_list, "mm10", "hg38", jaspar_pfm_list); gr_list_filter <- gr_candidate_filter(gr_list, best_k = 1L, threshold = 0.5)
```

## Evaluation signals

- Output gr_list entries carry logistic probability scores computed from both epigenomic and sequence grammar similarities
- gr_candidate_filter output retains at most best_k candidate target regions per query region (e.g., best_k = 1L)
- All retained candidate target regions have scores passing the chosen threshold (e.g., 0.5, or the threshold suggested by training_module with max_filter_proportion = 0.5)
- The threshold was chosen by the training module so that filtering does not remove too many candidate target regions
- In LOOCV (e.g., rat tissues: heart, liver, pancreas), candidates overlapping the held-out human orthologous epigenome peaks are labeled positive and recoverable by the scored ranking

## Limitations

- For species other than mouse, logistic regression parameters must be learned from a newly collected orthologous epigenome repertoire via training_module(); provided ENCODE-based defaults may not transfer
- Scoring quality depends on the availability of matched orthologous functional genomic datasets; datasets used for similarity are excluded in leave-one-out cross validation
- Existing sequence-conservation mapping approaches suffer from multi-mapping, low precision, and low mapping rate issues, which is the motivation for the probabilistic scoring layer
