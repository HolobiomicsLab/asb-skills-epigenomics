# de-novo-methylated-motif-discovery

## Summary

De novo identification of m5C methylase specificity motifs from RIMS-seq paired-end Illumina data by extracting foreground C-to-T (and G-to-A) positions with flanks and running MoSDi motif discovery with iterative masking.

## When to use

Use when analyzing paired-end RIMS-seq FASTQ reads (adapter-ligation libraries) from bacteria without a known methylome, to de novo determine m5C methylated motifs while also assembling/sequencing the genome.

## When NOT to use

- The sequencing library was prepared by tagmentation or other non-adapter-ligation protocols — RIMS-seq does not work in that case.
- The goal is precise genomic locations of methylation rather than global motif specificity — EM-seq or bisulfite-seq are more appropriate.
- An exact reference genome is available and you only need methylation calls from your own mapping (option 2), making SPAdes assembly unnecessary.

## Inputs

- Paired-end RIMS-seq FASTQ reads (e.g. ecoli_rims_3h_5M.1.fastq.gz / ecoli_rims_3h_5M.2.fastq.gz, adapter-ligation library, optionally downsampled to 1-5 million read pairs)
- BAM file of reads mapped to the assembled genome
- Read1 and Read2 mpileup files generated by samtools mpileup

## Outputs

- methylase_specificities.txt listing the de novo m5C methylated motifs (expected: CCWGG for E. coli K12 MG1655)
- Assembled reference genome (SPAdes) used for downstream motif discovery
- Intermediate foreground/background C-to-T sequence sets with 14 bp flanks fed to MoSDi

## How to apply

Run RIMS-seq.pl (option1) to assemble the reference genome from the paired-end reads with SPAdes — the reference must be derived from the RIMS-seq reads themselves since methylation is detected as C-to-T deamination relative to the sequenced genome. Map the reads back with BWA-mem via mapping.pl, then split the BAM into Read1/Read2 mpileup files using samtools mpileup via split_mapped_reads.pl. From the Read1 mpileup, extract foreground C-to-T (and G-to-A) positions using a minimum base quality score of 35 with 14 bp flanks (7 bp each side), extract matched background positions, and run mosdi-discovery with the parameter string '-T 1e-100 -M 8,1,0,4 8 occ-count'. Iteratively mask the top-scoring motif and re-run mosdi-discovery until no motif with P < 1e-100 remains; the remaining motifs are the methylase specificities. Downsample to 1-5 million paired-end reads before motif discovery to avoid lengthy processing times.

## Examples

```
mosdi-discovery -v discovery -q x -i -T 1e-100 -M 8,1,0,4 8 occ-count
```

## Evaluation signals

- methylase_specificities.txt exists in the output directory after the pipeline completes
- For the E. coli K12 MG1655 test data, the identified methylated motif matches the expected CCWGG
- The iterative masking loop terminates (no further motif with P < 1e-100 found) rather than cycling indefinitely
- Reported motifs fall in the expected 4-8 nt length range observed across bacteria in the paper (palindromic or non-palindromic)
- Genome assembly and sequencing QC metrics (coverage, GC content, mapping rate) are comparable to standard DNA-seq

## Limitations

- The library must be prepared with an adapter-ligation protocol; tagmentation-based protocols are incompatible with RIMS-seq.
- In microbial communities, closely related co-existing species make assigning motifs to the correct species challenging, and SNPs can confound C-to-T deamination detection, increasing background noise.
- Uneven species representation can cause motifs to be detected only in the most abundant species, and low-coverage or rare motif sites may not yield detectable signal; partially methylated sites need further evaluation of methylation pervasiveness.
- The option2 reference genome must be exactly the same as the sequenced bacterium; otherwise option1 (assembly from reads) is recommended.
- Skipping the column-based cleaning step (using a small library volume for amplification) is theoretically possible but has not been tested.
