# dna-methylation-call-from-bisulfite-free-reads

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Calls DNA methylation from bisulfite-free protocol reads (e.g., TAPS) using Msuite's unique 4-letter alignment mode, which preserves cytosines to exploit higher nucleotide complexity, then deduces CpG/CpH methylation densities for accuracy evaluation.

## When to use

Use when analyzing reads generated by bisulfite-free methylation assays such as TAPS or 5hmC-CATCH, where non-CpG methylation is low and the default 3-letter BS alignment wastes read complexity.

## When NOT to use

- Data generated by BS-seq protocols: 3-letter mode with -m BS is mandatory; 4-letter mode ONLY supports TAPS/5hmC-CATCH data where non-CpG methylation is very low
- Tissues with high non-CpG methylation (e.g., ESCs), which violate the low-CpH assumption of 4-letter analysis
- Input is already aligned BAM or an existing methylation call table — this skill performs alignment and calling jointly via Msuite

## Inputs

- paired-end TAPS FASTQ reads (read1.fq, read2.fq)
- reference genome FASTA with hg19 RefSeq annotation for index building
- SHERMAN-simulated benchmark reads with preset conversion rates (CpG 20%, CpH 0.5%)

## Outputs

- Msuite.CpG.meth.call methylation call table
- Msuite.CpH.meth.call methylation call table
- deduced methylation density comparison table and plot (e.g., methylation_density_comparison.png)
- BAM alignments (SAM converted via samtools)

## How to apply

First build genome indices with Msuite's build.index.sh utility, which automatically incorporates the Lambda genome for conversion-rate estimation. Run the msuite main program on paired-end TAPS FASTQ reads in 4-letter mode (Msuite -1 read1.fq -2 read2.fq -x hg19 -4 -m TAPS -o out.dir) and then execute make in the output directory. Parse the methylation call outputs Msuite.CpG.meth.call and Msuite.CpH.meth.call to compute the deduced methylation densities. On simulated benchmark data (SHERMAN-generated, preset 20% C->T CpG and 0.5% CpH conversion rates, 0.1% sequencing error), compare deduced versus preset densities per context and accept the call if residuals are near-zero at the level of the sequencing error rate; plot preset-vs-deduced differences in R (e.g., methylation_density_comparison.png).

## Related tools

- **Msuite** (all-in-one toolkit performing 4-letter alignment and CpG/CpH methylation calling for TAPS reads; index building via build.index.sh) — https://github.com/hellosunking/Msuite/
- **bowtie2** (underline aligner used by Msuite during converted-read alignment) — https://github.com/BenLangmead/bowtie2
- **samtools** (converting SAM format alignment files into BAM format)
- **SHERMAN script** (generates the in silico simulated paired-end benchmark reads with preset conversion rates)
- **R** (plots preset-vs-deduced methylation density differences and visualizations around TSS)

## Examples

```
Msuite -1 read1.fq -2 read2.fq -x hg19 -4 -m TAPS -o out.dir && cd out.dir && make
```

## Evaluation signals

- Deduced CpG density approximates the preset 20% C->T CpG conversion rate and deduced CpH density approximates the preset 0.5% CpH rate
- Per-context deduced-vs-preset density differences are at the level of the simulated 0.1% sequencing error rate (near-zero residuals)
- 4-letter mode outperforms 3-letter alternatives in mapping efficiency, accuracy, speed, and lower computing resource requirements
- SAM outputs convert cleanly to BAM with samtools and methylation call files (Msuite.CpG.meth.call / Msuite.CpH.meth.call) are produced after running make in the output directory

## Limitations

- No strong evidence that 4-letter mode is more accurate on inconsistent CpG sites; further validation needed
- Accuracy of 4- and 3-letter modes should be validated with additional methods (e.g., microarrays); current sequencing-based protocols have limitations
- On real TAPS data with imperfect chemical treatment, results remain high quality but the simulation-based accuracy check does not capture treatment imperfections
- 4-letter mode is only appropriate where non-CpG methylation is very low (e.g., most somatic tissues in human)
