# scatac-seq-celltyping-benchmark-evaluation

## Summary

Evaluates supervised scATAC-seq cell-typing predictions (e.g., Cellcano's two-round MLP/Knowledge Distiller outputs) against ground-truth labels by building a true-vs-predicted confusion matrix and checking diagonal counts, as in the Cellcano human PBMC quick-start demo.

## When to use

Use when benchmarking cell-typing predictions for scATAC-seq data — e.g., comparing Cellcano's predicted labels against FACS-derived ground truth for a human PBMC target dataset to quantify per-type accuracy.

## When NOT to use

- Input lacks a reference scATAC-seq dataset with known labels, so no supervised celltyping predictions (and hence no true-vs-predicted evaluation) can be produced
- The goal is cross-modality prediction using scRNA-seq as reference or multimodal (joint scRNA-/scATAC-seq) references — the article states these are planned but not implemented in Cellcano
- Input is already a labeled prediction-vs-truth table; then only the crosstab step is needed, not the full celltyping pipeline

## Inputs

- Cellcano prediction output for the target scATAC-seq dataset, with predicted cell-type labels per cell
- Target cell identifiers embedding ground-truth FACS labels (B, CD4 T, CD8 T, Mono, NK)
- Gene-score matrices for reference and target datasets generated by the ArchR pipeline (when running predictions from raw fragment/bam data)

## Outputs

- confusion_matrix.csv: 5x5 true-vs-predicted cross-tabulation with rows ordered B, CD4, CD8, Mono, NK
- Per-class diagonal (correct) counts, e.g., B 1022, CD4 T 1084, CD8 T 899, Monocytes 637, NK 637 in the quick-start demo

## How to apply

Run the supervised celltyping method (Cellcano: F-test selection of cell-type-specific genes on reference gene scores, first-round MLP prediction, entropy-based anchor selection, second-round self-Knowledge Distiller prediction of non-anchor cells), then pair each target cell's predicted label with its ground-truth label. In the Cellcano quick-start demo, FACS ground-truth labels (B, CD4 T, CD8 T, Monocytes, NK) are embedded in the target cell identifiers, so recover them by string-splitting the identifiers. Build a 5x5 pandas.crosstab of true vs predicted labels with rows ordered B, CD4, CD8, Mono, NK, and write it to confusion_matrix.csv. Judge success by whether the diagonal counts reproduce the quick-start-reported values (B 1022, CD4 T 1084, CD8 T 899, Monocytes 637, NK 637) and whether most target cells fall on the diagonal, mirroring the article's claim that Cellcano is accurate across 50 celltyping tasks from human PBMCs and mouse brain.

## Related tools

- **Cellcano** (Supervised celltyping method whose predictions are benchmarked; two-round MLP + self-Knowledge Distiller algorithm producing target cell-type labels) — https://marvinquiet.github.io/Cellcano/
- **ArchR** (Preprocesses raw scATAC-seq fragment/bam input into gene scores for both reference and target datasets prior to model training and evaluation) — https://www.archrproject.com/
- **EpiAnno** (Alternative supervised scCAS cell-annotation method (Bayesian neural network) usable as a comparator in the same celltyping benchmark) — https://github.com/xy-chen16/EpiAnno

## Examples

```
import pandas as pd; cm = pd.crosstab(pd.Series(true_labels, name='true'), pd.Series(pred_labels, name='pred')); cm.to_csv('confusion_matrix.csv')
```

## Evaluation signals

- Diagonal counts of the 5x5 crosstab approximately match the quick-start-reported values: B 1022, CD4 T 1084, CD8 T 899, Monocytes 637, NK 637; flag any diagonal cell deviating substantially
- Confusion matrix is written as confusion_matrix.csv with rows/columns ordered B, CD4 T, CD8 T, Monocytes, NK
- Ground-truth labels recovered by string-splitting the target cell identifiers must pair 1:1 with cells in the prediction output
- Majority of target cells lie on the diagonal, consistent with the article's claim that Cellcano is accurate across 50 celltyping tasks from human PBMCs and mouse brain

## Limitations

- Cellcano has not been tested on Apple M1 machines; installation there requires the workaround described in Issue #6
- Adaptation to cross-modality scenarios (scRNA-seq reference for scATAC-seq celltyping, single-cell DNA methylation) and multimodal (joint scRNA-/scATAC-seq) references are planned but not implemented
- Requires a specific dependency stack (python 3.8, tensorflow 2.7.1, anndata 0.7.4, scanpy 1.8.2, numpy 1.19.2, h5py 2.10.0, compatible keras/rpy2), and ArchR (R) is additionally required if input is raw fragment or bam data
