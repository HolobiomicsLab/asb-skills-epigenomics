# cpg-probe-feature-selection-sd-atc

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Feature selection of Illumina 450K CpG probes for cola consensus partitioning, comparing the variance-based top-value method SD against the correlation-structure-based ATC method on the GBM 450K methylation dataset (GSE36278). In this dataset SD-selected probes recover DKFZ GBM subgroups while ATC-selected probes track global methylation levels.

## When to use

Use when preprocessing an Illumina 450K methylation matrix for subgroup classification and deciding which top-value method (SD vs ATC) should drive CpG probe selection before consensus partitioning.

## When NOT to use

- When the goal is gene-expression subgrouping (e.g. RNA-Seq or microarray expression data), where the article's benchmarks favor ATC features and skmeans rather than the methylation-specific SD behavior
- When input probes have not yet been cleaned of sex-chromosome and SNP-overlapping probes — running SD/ATC selection on the raw matrix mixes global methylation artifacts into the feature scores
- When samples are ambiguous (silhouette score < 0.5) — cola excludes these from signature analysis, so downstream probe-set interpretation is unreliable

## Inputs

- GBM 450K methylation beta-value matrix from GEO accession GSE36278
- Illumina 450K probe annotation (CpG-island association categories)
- DKFZ GBM subtype classification labels for partition-agreement comparison

## Outputs

- Top-5000 SD-selected and ATC-selected probe sets with their overlap statistics
- CpG-island probe fractions per top-5000 set (60.6% SD vs 6.6% ATC expected)
- SD vs ATC partition-agreement statistics against DKFZ subtypes written to gbm_450k_sd_atc_comparison.csv
- Automated HTML report gbm_450k_cola_report.html generated by cola

## How to apply

Download the GBM 450K methylation matrix from GEO (GSE36278) with GEOquery and preprocess it with cola's adjust_matrix(): remove probes on sex chromosomes and probes overlapping known SNPs, impute missing values with impute.knn() from the R package impute, winsorize values at the 5th/95th percentiles, remove rows with zero variance and rows with variance below the 5th percentile of all row variances. Run cola's run_all_consensus_partitions() with top-value methods SD and ATC and the partitioning methods hclust, kmeans, skmeans, pam and mclust (NMF excluded), with row scaling disabled. Take the top 5000 probes by SD score and by ATC score, compute their intersection (expected near 1.76% overlap), and annotate both probe sets with Illumina 450K CpG-island association categories (expected CpG-island fractions: 60.6% for SD vs 6.6% for ATC). Finally, compare the SD- and ATC-based consensus partitions against the DKFZ GBM subtype classification by partition agreement to judge which feature set recovers the known subgroups.

## Examples

```
mat = adjust_matrix(mat); rl = run_all_consensus_partitions(mat, top_value_method = c("SD","ATC"), partition_method = c("hclust","kmeans","skmeans","pam","mclust"), scale_rows = FALSE)
```

## Evaluation signals

- SD/ATC top-5000 probe overlap is near the reported 1.76%
- CpG-island probe fractions are near 60.6% for the SD set and 6.6% for the ATC set
- SD-selected features recover the DKFZ GBM subtype classification by partition agreement, while ATC-selected features reflect global methylation level differences
- Preprocessed matrix contains no sex-chromosome probes, no known-SNP-overlapping probes, no missing values, and no rows with variance below the 5th percentile
- gbm_450k_cola_report.html is generated and gbm_450k_sd_atc_comparison.csv contains the agreement statistics

## Limitations

- ATC extraction on this methylation dataset mainly pulled features associated with global methylation changes rather than subtype-specific signals, so ATC is not the right choice here despite benchmarking well on expression data
- cola runtime and memory usage may be unacceptable for datasets with very high numbers of features/cells (e.g. scRNA-Seq with several thousands of cells)
- Downsampling strategies used inside consensus partitioning may miss small clusters
- No changelog available in the manuscript repository metadata, limiting reproducibility of versioned results
