# ranked-transcription-factor-list-overlap-analysis

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Quantifies pairwise concordance of top-ranked transcriptional regulator (TR) lists produced by different TR-identification methods (BIT, BART, ChIP-Atlas, i-cisTarget, HOMER, WhichTF) by computing Jaccard indices at top-k cutoffs, revealing how much the methods agree on the same epigenomic query region sets.

## When to use

Use when two or more tools output ranked TR lists for the same query region sets (e.g., TR perturbation-derived DARs or cancer-type-specific accessible regions) and you need pairwise top-k list agreement via Jaccard indices.

## When NOT to use

- Only one method's ranked TR list is available — pairwise Jaccard requires at least two ranked lists for the same region set
- The goal is to measure accuracy rather than inter-method agreement — use mean reciprocal rank (MRR) against known perturbed TRs, as the article did for five perturbed TRs in bulk datasets
- The objects to compare are genomic region sets (BED peaks) rather than ranked TR name lists — Jaccard here is computed over top-k TR sets, not over genomic intervals

## Inputs

- Ranked TR tables (per-method ordered lists of transcriptional regulator names with scores) for the same query region sets
- Top-k cutoffs (k = 10, 50, 100)
- Query region-set definitions (e.g., TR perturbation-derived DARs; cancer-type-specific accessible regions from TCGA)

## Outputs

- Method-by-method Jaccard similarity matrices for each top-k cutoff and region-set type (CSV)
- Heatmaps of the pairwise Jaccard similarity matrices (mirroring Supplementary Fig. 9)
- Optional per-method MRR values for benchmarking against known perturbed TRs

## How to apply

Load the ranked TR tables generated by each method — in the reference study, BIT, BART2, ChIP-Atlas, i-cisTarget, HOMER, and WhichTF applied to TR perturbation-derived DARs and cancer-type-specific accessible regions. For each query region set and each top-k cutoff (k = 10, 50, 100), extract the set of top-k ranked TR names per method and compute all pairwise Jaccard indices as |intersection| / |union| of the top-k TR sets. Assemble the values into method-by-method similarity matrices for each k and region-set type, write them to CSV, and render each matrix as a heatmap mirroring Supplementary Fig. 9. To complement overlap with accuracy, benchmark the same ranked lists using mean reciprocal rank (MRR) against known perturbed TRs, as the study did for five perturbed TRs in bulk datasets.

## Examples

```
Rscript -e 'jaccard <- function(a,b) length(intersect(a,b))/length(union(a,b)); J <- outer(top10, top10, Vectorize(function(x,y) jaccard(topk[[x]], topk[[y]]))); write.csv(J, "jaccard_top10.csv")'
```

## Evaluation signals

- All pairwise Jaccard values fall in [0, 1] and the matrix is symmetric with a diagonal of 1 (each method's top-k set perfectly overlaps itself)
- Reproduced pairwise Jaccard values are generally low across methods, consistent with the paper's Supplementary Fig. 9
- One similarity matrix is produced per top-k cutoff (k = 10, 50, 100) and per region-set type; matrices are 6x6 for the six methods
- Every cell's Jaccard equals |intersection| / |union| of the two methods' top-k TR name sets with a non-empty union
- Output CSVs contain the method-by-method matrices and heatmaps visually match Supplementary Fig. 9 layout

## Limitations

- Jaccard similarity measures agreement between methods but does not by itself identify which method's ranking is biologically correct; the paper complemented it with MRR against perturbed TRs
- Reproducibility gap: the comparison references Supplementary Figures 9, 10a, 10b, and 10c, which are not present in the provided article text, so the expected heatmap values must be obtained from the SI
- Top-k overlap is sensitive to the chosen cutoffs (k = 10, 50, 100) and to ties in ranking near the cutoff boundary
