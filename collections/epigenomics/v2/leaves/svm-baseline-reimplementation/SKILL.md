# svm-baseline-reimplementation

## Summary

Reimplements the iDNA6mA-PseKNC predictor as an SVM baseline (C=0.336, gamma=0.02) evaluated by 5-fold cross-validation on the same Motif+Kmer+Binary feature matrices used by csDMA, enabling a head-to-head AUC/ACC/Sn/Sp/MCC comparison (Table 4).

## When to use

Use when a study claims a new 6mA-site predictor outperforms iDNA6mA-PseKNC and the comparison must be reproduced under identical 5-fold cross-validation on cross-species, rice, or M. musculus datasets.

## When NOT to use

- The input is already a per-fold cross-validation score file or a finished comparison table — no reimplementation is needed.
- The question concerns independent-test-set performance or LeaveOneOut evaluation rather than the 5-fold cross-validation comparison against iDNA6mA-PseKNC.
- A direct i6mA-Pred comparison is requested — the article notes i6mA-Pred was still in corrected proof phase and its method could not be reached, so no faithful reimplementation exists in this repo.

## Inputs

- Training positive and negative 41nt DNA sequence datasets (FASTA) for the cross-species, rice, and M. musculus benchmarks
- Motif feature score matrices (matrix_motif1, matrix_motif2) generated by feature_selection.py using the Motif + Kmer + Binary encoding
- SVM hyperparameters for the iDNA6mA-PseKNC baseline (C=0.336, gamma=0.02)

## Outputs

- Per-dataset 5-fold cross-validation score files for csDMA (ExtraTrees) and the SVM baseline
- Comparison table table4_cross_validation_results.csv with AUC, ACC, Sn, Sp, MCC for both predictors on cross-species/rice/M. musculus

## How to apply

Encode the training positive/negative FASTA datasets of each benchmark (cross-species 2,768/2,716; rice 880/880; M. musculus 1,934/1,934, all 41nt) into motif score matrices (matrix_motif1, matrix_motif2) using feature_selection.py, so both predictors see identical features. Train the baseline as an SVM with the hyperparameters reported for iDNA6mA-PseKNC (C=0.336, gamma=0.02) — scikit-learn's SVM is one of the classifiers selectable in classifier_selection.py alongside the csDMA ExtraTrees model. Run 5-fold cross-validation of both the baseline SVM and the ExtraTrees csDMA model on each dataset's encoded matrix, then compute AUC, ACC, Sn, Sp and MCC per dataset. Assemble the side-by-side metrics into a table mirroring Table 4 (csDMA AUC 0.879/0.923/0.965 vs iDNA6mA-PseKNC 0.844/0.896/0.974 on cross-species/rice/M. musculus) and save as CSV. Rationale: only by evaluating both predictors on the same feature encoding and CV splits does the comparison isolate the classifier rather than the featurization.

## Related tools

- **csDMA** (Candidate predictor trained with the ExtraTrees classifier on the shared feature matrices; provides the upper arm of the comparison) — https://github.com/liuze-nwafu/csDMA
- **iDNA6mA-PseKNC** (Existing predictor reimplemented as an SVM (C=0.336, gamma=0.02) baseline evaluated under the same 5-fold cross-validation)

## Examples

```
python classifier_selection.py train_positive_dataset train_negative_dataset matrix_motif1 matrix_motif2
```

## Evaluation signals

- The reimplemented iDNA6mA-PseKNC SVM baseline reproduces the published AUC ordering: lower than csDMA's ExtraTrees on cross-species (0.844 vs 0.879) and rice (0.896 vs 0.923), but higher on M. musculus (0.974 vs 0.965).
- Both predictors are scored on identical matrix_motif1/matrix_motif2 inputs and identical 5-fold CV splits; any metric difference is attributable to the classifier, not featurization.
- All five metrics (AUC, ACC, Sn, Sp, MCC) are reported per dataset per predictor, mirroring Table 4's schema.
- The SVM baseline uses exactly C=0.336 and gamma=0.02; deviations from these hyperparameters invalidate the comparison.
- Output CSV is named table4_cross_validation_results.csv and values fall in [0,1] with csDMA-vs-baseline deltas consistent with the paper's claims.

## Limitations

- i6mA-Pred could not be directly compared because the paper was still in corrected proof phase and its method was unreachable; its performance was known only from an online abstract (ACC 0.831 by jackknife test).
- csDMA performance on the rice and cross-species datasets was relatively low despite outperforming the baseline.
- csDMA was implemented in Python 2.7, which may complicate reproduction in modern environments.
