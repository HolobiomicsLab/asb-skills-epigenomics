# adjusted-mutual-information-partition-comparison

## Summary

Quantifies agreement between two sets of genomic partition predictions (e.g., TLDs predicted from noisy vs. original downsampled Hi-C matrices) using adjusted mutual information (AMI) from scikit-learn, complemented by weighted similarity (WS), to assess robustness of TLD predictors such as deDoc2 to data noise.

## When to use

Use when comparing two genome partition/TLD call sets — e.g., predictions from noise-perturbed vs. original downsampled Hi-C matrices — to measure how much domain structure is preserved.

## When NOT to use

- When comparing raw contact matrices rather than discrete partition/domain predictions — AMI operates on bin-level partition labels, not contact frequencies
- When the two call sets come from different bin sizes or genomic coordinates, since bins cannot be aligned into comparable partition vectors
- When you need boundary-level accuracy rather than partition-level agreement; the article's WS excludes intermediate windows of domains, and boundary-specific metrics would be a different analysis

## Inputs

- TLD predictions (partition vectors over 40 kb bins) from original downsampled bulk Hi-C matrices (Rao et al., 0.025% sampling rate)
- TLD predictions from noisy versions of the same matrices at 10%, 20%, and 40% noise rates
- Optional: intermediate windows of predicted TLDs for AMI computation

## Outputs

- AMI values per (predictor, noise level) pair, computed via sklearn.metrics.adjusted_mutual_info_score
- Weighted similarity (WS) values per (predictor, noise level) pair
- Summary table noise_robustness_ami_ws.csv with AMI and WS across 10%, 20%, and 40% noise rates

## How to apply

Run the TLD predictors (deDoc2, deDoc, SpectralTAD-class network detectors, and score-based detectors such as scHiCluster, deTOKI, Higashi) separately on the original downsampled Hi-C matrices (0.025% sampling rate, default 40 kb binsize) and on noisy versions generated by randomly selecting 10%, 20%, or 40% of entries with replacement and adding a constant of one, sampled per secondary diagonal according to the distance-dependent contact probability computed as in Boost-HiC, restricted to rows/columns with at least one nonzero entry. For AMI, convert each predicted domain set into a bin-level partition vector and compute sklearn.metrics.adjusted_mutual_info_score between the original and noisy partitions, including all predicted TLDs and intermediate windows of TLDs in T and K. For weighted similarity (WS), place original predictions in T and noisy predictions in K and exclude intermediate windows of domains. Assemble AMI and WS per noise level and predictor into a table (noise_robustness_ami_ws.csv). AMI corrects for chance agreement, so values near the noise-free baseline indicate a robust predictor; in this analysis deDoc2.w achieved the highest AMI and WS among all predictors, with both metrics decreasing only slightly as noise rate increased.

## Examples

```
from sklearn.metrics import adjusted_mutual_info_score; ami = adjusted_mutual_info_score(labels_original, labels_noisy)
```

## Evaluation signals

- noise_robustness_ami_ws.csv exists and contains AMI and WS entries for every (predictor, noise level) combination at 10%, 20%, and 40%
- AMI and WS values decrease only slightly as the noise rate increases from 10% to 40% for a robust predictor, reproducing the reported noise-robustness pattern
- deDoc2.w ranks highest in both AMI and WS among all evaluated predictors at each noise level
- AMI is computed with intermediate windows of TLDs included in T and K, while WS excludes intermediate windows and places original predictions in T and noisy predictions in K
- Partition vectors for AMI cover the same 40 kb bins for both original and noisy predictions, so adjusted_mutual_info_score receives aligned label arrays

## Limitations

- All predictors were run with default settings except Higashi (nbr = 0, embedding_epoch = 1, no_nbr_epoch = 20 for downsampled data), and no version numbers were stated for any tool
- Noise is introduced only into downsampled bulk Hi-C matrices at 0.025% single-cell-level sparsity; behavior at other sampling rates or on genuinely sparse single-cell data is not covered by this protocol
- AMI and WS measure partition agreement and may not capture differences in hierarchical domain structure or boundary precision
