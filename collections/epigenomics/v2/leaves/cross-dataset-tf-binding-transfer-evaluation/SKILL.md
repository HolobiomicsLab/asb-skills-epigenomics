# cross-dataset-tf-binding-transfer-evaluation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Benchmarking skill that measures how well a transcription factor binding affinity model trained on HT-SELEX per-cycle enrichments transfers to uPBM data, using DNAffinity's random forest (average Pearson 0.47) against DeepBind, BEESEM, BindSpace, and DeepSELEX baselines.

## When to use

Use when evaluating cross-platform transfer of a TF binding affinity model — train on HT-SELEX per-cycle enrichment data, test on uPBM affinities, and benchmark Pearson correlation against DeepBind, BEESEM, and BindSpace.

## When NOT to use

- Training and test data come from the same platform (e.g. an 80/20 uPBM or gcPBM split) — use the paper's within-dataset R2 evaluation instead (gcPBM 0.93 ± 0.02, uPBM 0.69 ± 0.17)
- The goal is in vivo binding site prediction — combine in vitro predictions with yeast G1-phase nucleosome positioning maps rather than running cross-dataset transfer
- Input files do not follow the required layouts (proteins/{protein}/{cycle}.txt for selex_regressor.py, proteins/{protein}/{protein}_training.txt for upbm_regressor.py) — the regressors expect these exact templates

## Inputs

- HT-SELEX per-cycle enrichment files at proteins/{protein}/{cycle}.txt
- uPBM training files at proteins/{protein}/{protein}_training.txt
- MEME suite motif results used to trim uPBM sequences
- Competitor method runs (DeepBind, BEESEM, BindSpace, DeepSELEX) trained and tested on the same TF set

## Outputs

- Per-TF uPBM affinity predictions generated by the HT-SELEX-trained DNAffinity model (via upbm_regressor.py)
- Per-TF and average Pearson correlations between predicted and experimental uPBM affinities
- cross_dataset_correlations.csv — per-method average Pearson table (DNAffinity 0.47 vs DeepSELEX 0.41, BEESEM 0.36, DeepBind 0.35, BindSpace 0.20)

## How to apply

Collect the required files and verify formatting against the README templates: HT-SELEX per-cycle enrichment files at proteins/{protein}/{cycle}.txt and uPBM training files at proteins/{protein}/{protein}_training.txt. Apply SVM filtering to discard HT-SELEX cases whose enrichments are inconsistent across cycles, and trim uPBM sequences using the MEME suite motif result to reduce sequence variability. Launch selex_regressor.py (protein name as 1st argument, cycle number as 2nd) to extract DNA physical-property features and train the random forest regressor on HT-SELEX affinities, then run upbm_regressor.py to apply the HT-SELEX-trained model to the uPBM data for the same TFs. Compute the Pearson correlation between predicted and experimental uPBM affinities per TF and average across TFs, validating DNAffinity against the reported ~0.47 benchmark. Rerun the competitor methods (DeepBind, BEESEM, BindSpace, plus DeepSELEX/DNAShapeR) trained and tested on the same TFs, record their average Pearson correlations, and assemble the per-method table as cross_dataset_correlations.csv.

## Related tools

- **DNAffinity** (Physics-based random forest regressor trained on HT-SELEX per-cycle affinities (selex_regressor.py) and applied to uPBM data (upbm_regressor.py) for the transfer test) — https://github.com/Jalbiti/DNAffinity
- **MEME suite** (Motif discovery used to trim uPBM sequences before the transfer evaluation, reducing sequence variability)

## Examples

```
python selex_regressor.py Gata4 4; python upbm_regressor.py Gata4
```

## Evaluation signals

- DNAffinity's average Pearson correlation should reproduce the reported ~0.47 on the HT-SELEX-to-uPBM transfer
- Competitor averages should land near reported values — DeepBind 0.35, BEESEM 0.36, BindSpace 0.20, DeepSELEX 0.41 — with DNAffinity outperforming all on the same TF set
- Input files must match the README templates (proteins/{protein}/{cycle}.txt and proteins/{protein}/{protein}_training.txt) before launching the regressors
- HT-SELEX cases flagged inconsistent across cycles by the SVM filter must be excluded, and uPBM sequences must be trimmed using the MEME suite motif, before training/testing
- cross_dataset_correlations.csv must contain one average Pearson value per method, all computed on the same TF set

## Limitations

- The transcription factor binding site concept is not uniquely defined — it depends on the intrinsically noisy and low-resolution experimental technique used to detect it, so cross-platform transfer scores are technique-limited
- In vitro predictions cannot be straightforwardly extrapolated to in vivo settings where other factors besides intrinsic TF affinity play a role, and DNAffinity predicts many potential binding sites where no experimental in vivo binding evidence exists
- Cross-platform transfer performance (Pearson 0.47) is far below within-platform fits (gcPBM R2 0.93 ± 0.02, uPBM R2 0.69 ± 0.17), indicating substantial platform-specific bias
