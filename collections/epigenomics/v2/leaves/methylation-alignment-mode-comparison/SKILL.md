# methylation-alignment-mode-comparison

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Benchmark Msuite's unique 4-letter alignment mode against its 3-letter mode and 3-letter tools (Bismark, BWA-meth) on in silico TAPS reads simulated from CT/GA-rich human genome bins, quantifying mapping efficiency and accuracy per aligner and region class.

## When to use

Use when comparing DNA methylation read aligners (4-letter vs 3-letter) on TAPS/bisulfite-free reads, especially for CT/GA-rich regions where 3-letter C->T conversion collapses mapping power.

## When NOT to use

- Data are generated by standard bisulfite (BS-seq) protocols — the README states 4-letter mode only supports TAPS/5hmC-CATCH data and BS data MUST use 3-letter mode with -m BS
- You only need routine alignment of one sample rather than a controlled mode-vs-tool comparison benchmark
- Evaluation requires strong evidence of 4-letter accuracy on inconsistent CpG sites — the authors note such evidence is lacking and recommend validation with additional methods such as microarrays

## Inputs

- In silico paired-end 36-bp FASTQ reads simulated by SHERMAN under TAPS protocol parameters
- Human reference genome FASTA (e.g., hg19/hg38) plus RefSeq annotation
- Bismark and BWA-meth genome indices
- CT/GA proportion-stratified 500-bp genomic bins from the Msuite benchmark scripts

## Outputs

- Per-aligner mapping efficiency (%) and accuracy (%) stratified by CT/GA region class (>=70%, >=80%)
- table2_ct_ga_mapping_efficiency.csv reproducing the CT/GA rows of the paper's Table 2

## How to apply

Simulate 1,000,000 paired-end 36-bp reads with the SHERMAN script following the TAPS protocol (C->T rate 20% at CpG, 0.5% at CpH, 0.1% error), sampling 500-bp hg19/hg38 bins stratified by CT/GA proportion >=70% and >=80% from the Msuite benchmark scripts. Build Msuite indices with build.index/build.index.sh (genome FASTA plus RefSeq annotation; Lambda control is auto-incorporated), then align reads in 4-letter mode (-4 -m TAPS) and 3-letter mode (-3 -m TAPS), running 'make' in each output directory to execute the full pipeline. Align identical read sets with Bismark and BWA-meth, which perform 3-letter conversion via bowtie2, under matched settings. Compute per-aligner mapping efficiency and accuracy per CT/GA class, counting only reads with unique best hits; reads mapping to multiple loci with equal best scores are discarded.

## Related tools

- **Msuite** (Primary aligner run in both 4-letter (-4 -m TAPS) and 3-letter (-3 -m TAPS) modes; indices built with build.index.sh) — https://github.com/hellosunking/Msuite/
- **SHERMAN script** (Generates in silico paired-/single-end 36-/100-bp benchmark read sets)
- **Bismark** (3-letter bowtie2-based comparator aligner for the same read sets)
- **BWA-meth** (3-letter comparator aligner for the same read sets)
- **bowtie2** (Underline aligner used by Msuite and Bismark) — https://github.com/BenLangmead/bowtie2
- **samtools** (Converting SAM format alignment outputs into BAM format) — http://samtools.sourceforge.net/

## Examples

```
msuite -4 -m TAPS -x hg19 -1 reads_R1.fq.gz -2 reads_R2.fq.gz -c 36 -o out.4letter && make -C out.4letter
```

## Evaluation signals

- Reproduced mapping efficiency for Msuite 4-letter mode on CT/GA >=70% bins matches the reported 79.67% ME (vs 67.14% for 3-letter mode)
- All four aligners are run on identical FASTQ inputs with matched settings; only unique best hits counted, multi-mapping reads with equal best scores discarded
- table2_ct_ga_mapping_efficiency.csv contains rows for each aligner per CT/GA region class and the 4-letter advantage grows for >=80% bins
- Msuite indices built successfully for both Watson and Crick chains with Lambda genome auto-incorporated by build.index.sh
- Accuracy of BWA-meth (~92%) is clearly lower than Bismark and both Msuite modes (>98%), matching the reported ordering

## Limitations

- No strong evidence that 4-letter mode is more accurate on inconsistent CpG sites; further validation needed
- Accuracy of 4- and 3-letter modes should be validated with additional methods (e.g., microarrays) given limitations of current sequencing-based protocols
- 4-letter mode requires low non-CpG methylation (TAPS/5hmC-CATCH); real TAPS datasets had imperfect chemical treatment
- Msuite and Bismark differ in speed and memory despite sharing bowtie2, so runtime may confound head-to-head comparisons
