# false-positive-rate-estimation-at-alpha

## Summary

Estimates the empirical false positive rate of a genomic range overlap test at a nominal significance threshold alpha, comparing block-bootstrapped nulls (bootRanges) against conventional shuffling. It exposes how overly narrow shuffling-based null distributions inflate significance.

## When to use

Use when simulating or reanalyzing two genomic range sets x and y with no true association, to check whether a null-generation method (block bootstrap vs shuffling) controls FPR near alpha.

## When NOT to use

- x and y have a true biological association — the simulation and FPR validation assume no true association
- The goal is point estimation of an overlap rate rather than calibration/type-I-error assessment of a null-generation scheme
- The input is not interval-valued genomic ranges (e.g. already-summarized p-values without range coordinates)

## Inputs

- Simulated GRanges objects x and y with no true association (Supplementary Section S2.1 spec)
- Block-bootstrapped null GRanges sets of x generated by bootRanges
- Shuffled null GRanges sets of x generated by conventional permutation (bootstrap.R scheme)

## Outputs

- Per-iteration overlap rates between null x and y
- Variance and z-score statistics per null method (var.R-style)
- fpr_simulation_results.csv tabulating FPR for bootRanges versus shuffling at threshold alpha

## How to apply

Simulate two genomic range sets x and y with no true association following the Supplementary Section S2.1 simulation spec. Generate null x range sets with bootRanges (nullranges package) so the block bootstrap preserves local genomic correlation structure, and in parallel generate nulls with conventional shuffling via the bootstrap.R-style scheme. For each null iteration compute the overlap rate between null x and y, then apply var.R-style variance and z-score computation. Repeat over many simulation replicates and estimate the FPR of each method at the nominal threshold alpha, tabulating bootRanges versus shuffling FPR into fpr_simulation_results.csv. The rationale is that shuffling can produce null distributions with a similar mean but much lower variance, so z-scores become over-estimated and FPR rises above alpha, whereas the block bootstrap stays calibrated near alpha.

## Related tools

- **bootRanges** (Generates block-bootstrapped null genomic ranges preserving local genomic correlation structure, used as the calibrated null for FPR comparison) — https://bioconductor.org/packages/nullranges
- **nullranges** (R/Bioconductor package hosting bootRanges; installed and loaded to run the block bootstrap) — https://bioconductor.org/packages/nullranges

## Examples

```
Rscript segBootranges.R && Rscript var.R && Rscript bootstrap.R
```

## Evaluation signals

- bootRanges FPR is close to the nominal alpha (correct calibration)
- Shuffling-based FPR is clearly elevated above alpha, reflecting over-estimation of statistical significance
- Shuffling null distribution has a similar mean to bootRanges nulls but much lower variance
- Results table fpr_simulation_results.csv is produced with FPR columns for both methods across replicates
- Z-score computation matches the var.R-style variance-of-overlap-rate formulation

## Limitations

- Shuffling or permutation schemes may result in overly narrow test statistic null distributions and over-estimation of statistical significance
- Conclusions rest on the Supplementary Section S2.1 no-association simulation setup; other simulation geometries may need re-validation
