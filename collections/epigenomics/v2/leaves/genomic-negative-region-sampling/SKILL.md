# genomic-negative-region-sampling

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Generates matched negative genomic regions with bedtools shuffle so that positive-vs-negative ROC/AUC evaluation of RNA:DNA triplex (TPX) prediction is not biased by region length or mappability confounders.

## When to use

Use when building a positive/negative benchmark for genomic prediction tools (e.g. 3plex TPX scoring): you have experimentally derived peak sets (IDR, Overlap q<0.05, Top1000) and need randomised genomic regions matched to the positives' length distribution while excluding positives, genome gaps and ENCODE blacklist regions.

## When NOT to use

- When the analysis goal is per-nucleotide or per-triplex validation (e.g. comparing 3plex with TriplexFPP predictions) rather than region-level enrichment testing — negatives generated by shuffle do not address prediction agreement.
- When positives lack a defined replicate-consistent peak set: only 2 of 7 TPX-validated lncRNAs had IDR conservative peaks, so shuffle-based benchmarking cannot be applied uniformly.
- When evaluating binding within specific promoter sets or JASPAR TF PWM-defined regions, where randomised genomic negatives would not respect the constrained search space.

## Inputs

- Positive binding peak set in BED format (e.g. Top1000 RNA:DNA interaction peaks, IDR conservative/optimal peaks, Overlap conservative q<0.05 peaks, or author-provided peaks)
- Genome assembly chromosome sizes file for bedtools shuffle
- Genome gap (N-region) track to exclude
- ENCODE blacklist region BED file to exclude

## Outputs

- BED file of shuffled negative genomic regions with a length distribution matched to the positive peaks
- One-to-one positive/negative region pairs used as input to 3plex/Triplexator scoring and pROC AUC computation

## How to apply

For each lncRNA positive peak set (e.g. the Top1000 RNA:DNA interaction peaks or IDR conservative thresholded peaks from ENCODE), run bedtools shuffle over the same genome assembly so that the length distribution of the sampled negatives mirrors the positives. Constrain the shuffle with three exclusion masks: the positive regions themselves, genome gap (N) tracks, and ENCODE blacklist regions, so negatives are neither trivially overlapping signals nor unmappable or artefact-prone sequence. Keep negatives one-to-one with positives so pROC ROC/AUC computation and one-sided Mann-Whitney tests with Benjamini-Hochberg correction compare like-sized sets. The rationale is that without matched, filtered negatives, scores like the Triplexator potential or Normalised stability would be inflated by GC-rich or blacklist-associated regions rather than reflecting genuine TPX enrichment.

## Related tools

- **bedtools** (Generates matched negative genomic regions by shuffling positive peak coordinates while preserving length distribution and excluding positives, genome gaps and ENCODE blacklist regions)
- **pROC** (Consumes scores computed on the shuffled negatives alongside positives to compute ROC curves and AUC values (v1.17.0.1 in the paper))
- **3plex** (Scores both positive peaks and bedtools-shuffled negatives for TPX formation to enable AUC-based benchmarking) — https://github.com/molinerisLab/3plex

## Examples

```
bedtools shuffle -i positives.bed -g hg38.chrom.sizes -excl positives.bed gaps.bed encode_blacklist.bed > negatives.bed
```

## Evaluation signals

- Negative-region length distribution is statistically indistinguishable from the positive peaks' length distribution after bedtools shuffle.
- Zero overlap between shuffled negatives and the positive peaks, genome gaps, or ENCODE blacklist regions (verify with bedtools intersect).
- The positive set shows significant score separation from negatives: one-sided Mann-Whitney test with Benjamini-Hochberg FDR < e-10 for strong TPX candidates (e.g. MALAT1, HAND2-AS1, AK156552.1 with AUC > 0.8).
- AUC values computed with pROC fall within [0, 1] and reproduce the reported evidence tiers when the classification table is regenerated.

## Limitations

- Shuffled negatives are randomised with respect to sequence composition; GC-content or chromatin-state confounders are not explicitly matched beyond blacklist exclusion, so AUC gains may partly reflect sequence composition rather than triplex potential.
- Only 2 of 7 TPX-validated lncRNAs had IDR conservative peaks; the other 5 showed insufficient replicate reproducibility, forcing reliance on weaker peak sets (Overlap conservative q<0.05 or Top1000) for negative matching.
- bedtools shuffle depends on the chosen genome assembly and gap/blacklist tracks; mismatched assembly versions between positives and exclusion masks will silently corrupt the negatives.
