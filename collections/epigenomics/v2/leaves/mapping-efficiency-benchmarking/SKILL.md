# mapping-efficiency-benchmarking

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Benchmark the mapping efficiency and accuracy of DNA methylation aligners (Msuite 4-letter/3-letter modes, Bismark, BWA-meth) on in silico reads simulated from CT/GA-rich genomic regions, to quantify whether 4-letter alignment outperforms 3-letter conversion-based mapping on TAPS-protocol data.

## When to use

Use when comparing aligners for bisulfite-free (e.g., TAPS) methylation data on reads from CT/GA-rich regions, where C-to-T conversion erases strand information and 3-letter mapping loses efficiency.

## When NOT to use

- Input data are real bisulfite-seq (BS-seq) libraries: Msuite 4-letter mode only supports TAPS/5hmC-CATCH data with very low non-CpG methylation, so this benchmark design does not apply to BS-seq.
- Reads are long or generated by non-TAPS, non-BS protocols without matching kit settings (Msuite accepts only 'illumina', 'nextera', 'bgi' kits).

## Inputs

- Simulated paired-end 36-bp FASTQ reads (SHERMAN, TAPS protocol: 20% CpG / 0.5% CpH conversion, 0.1% error)
- Human reference genome FASTA (hg19/hg38) with RefSeq annotation
- CT/GA-proportion-stratified 500-bp genomic bins (>=70% and >=80%) from the Msuite GitHub deposit
- Bismark and BWA-meth genome indices built on the same reference

## Outputs

- Per-aligner mapping-efficiency table stratified by CT/GA region class (table2_ct_ga_mapping_efficiency.csv)
- Per-aligner accuracy estimates (percentage of reads mapped to their true bin of origin)
- SAM/BAM alignment files per aligner per read set

## How to apply

Simulate 1,000,000 paired-end 36-bp in silico reads with the SHERMAN script following the TAPS protocol (C->T conversion rate 20% at CpG sites, 0.5% at CpH sites, 0.1% error rate), sampling 500-bp human-genome bins stratified by CT/GA proportion >=70% and >=80%. Build Msuite indices with build.index/build.index.sh for the human reference (hg19/hg38 with RefSeq annotation) and matching Bismark/BWA-meth indices. Align each read set with Msuite in 4-letter mode ('-4 -m TAPS') and 3-letter mode ('-3 -m TAPS') plus Bismark and BWA-meth under matched settings, then compute per-aligner, per-region mapping efficiency counting only unique best hits, discarding multi-mapping reads with equal best scores. Validate against the reported benchmark: Msuite 4-letter ME 79.67% and accuracy 99.78% versus 3-letter 67.14%/99.03%, Bismark 68.39%/98.94%, and BWA-meth 76.31%/92.06% on CT/GA >=70% bins, with the 4-letter advantage growing for CT/GA >=80%.

## Examples

```
build.index/build.index.sh hg19.fa refSeq.txt hg19 && msuite -4 -m TAPS -x hg19 -1 sim_R1.fq -2 sim_R2.fq -o out.dir && cd out.dir && make
```

## Evaluation signals

- Msuite 4-letter mapping efficiency on CT/GA >=70% bins should reproduce ~79.67% (3-letter ~67.14%, Bismark ~68.39%, BWA-meth ~76.31%).
- Msuite 4-letter accuracy should approach ~99.78% versus ~99.03% (3-letter), ~98.94% (Bismark), and ~92.06% (BWA-meth).
- The 4-letter versus 3-letter mapping-efficiency gap should widen when restricted to CT/GA >=80% bins.
- Read counts must exclude multi-mapping reads with equal best scores on the same strand; only unique best hits count toward ME.
- All aligners must be run on the identical 1,000,000 paired-end read set with matched reference indices for a fair comparison.

## Limitations

- The article notes no strong evidence that 4-letter mode is more accurate on inconsistent CpG sites; further validation is needed.
- Accuracy of 4- and 3-letter modes should ideally be validated with orthogonal methods (e.g., microarrays) given the limitations of current sequencing-based protocols.
- Real TAPS datasets suffer imperfect chemical treatment, which can shift real-data results away from the simulated benchmark.
- 4-letter mode is restricted to TAPS/5hmC-CATCH data with very low non-CpG methylation (e.g., most somatic tissues); BS-seq data must use 3-letter mode with '-m BS'.
